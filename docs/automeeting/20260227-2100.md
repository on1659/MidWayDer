## 구현 대상 (v0.4.9)

### ① 카테고리 변경 → 자동 재검색 (72점) ← **핵심**

**변경 파일**: `src/app/page.tsx`

- `autoSearchTimerRef` useRef 추가
- `handleCategoryChange(cat)` 추가:
  - setCategory(cat) 항상 호출
  - hasSearched=true + start/end 있음 + !isLoading → 800ms 디바운스 후 clearResults→search
- 데스크탑 CategorySelect onChange → handleCategoryChange
- 모바일 SearchOverlay onCategoryChange → handleCategoryChange

**UX**: 사용자가 "스타벅스"에서 "이디야"로 카테고리 바꾸면 0.8초 후 자동으로 재검색됨.
재검색 중엔 로딩 인디케이터 표시. 검색 전(hasSearched=false) 상태에선 변화 없음.

---

### ② 로딩 중 취소 버튼 (63점)

**변경 파일**: `src/components/search/ResultList.tsx`, `src/app/page.tsx`

- ResultList props에 `onCancel?: () => void` 추가
- isLoading 화면 하단에 "취소" 버튼 렌더링
- page.tsx에서 `onCancel={cancelSearch}` 전달

---

### ③ 정렬 기준 배지 강조 (48점)

**변경 파일**: `src/components/search/ResultList.tsx`, `src/app/page.tsx`

- ResultList props에 `sortBy?: 'score' | 'distance' | 'duration'` 추가
- `sortBy === 'distance'`: +km 배지 → 진한 accent (bg: accent, color: white)
- `sortBy === 'duration'`: +분 배지 → 진한 yellow (bg: yellow-400, color: white)
- `sortBy === 'score'`: 점수 버튼 → 살짝 강조 (이미 active 상태와 구분 필요)
- page.tsx에서 `sortBy={sortBy}` 전달
