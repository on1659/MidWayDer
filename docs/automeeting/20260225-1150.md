### A. **주유소 카테고리 추가 - "실제 수요 1위" ⛽ 긴급**

**현재 문제:**
- 카페/편의점 위주 카테고리
- **실제로 경로 중간에 가장 많이 찾는 건 주유소**
- 주유소는 "이탈 거리/시간 민감도"가 가장 높은 카테고리
- 경쟁 서비스 (카카오맵, 네이버맵) 대비 차별화 가능

**시장 데이터:**
- 전국 주유소: 약 12,000개
- 일평균 주유소 검색: 수십만 건 (네이버맵 기준)
- "운전 중 경유지" 1순위 = 주유소

**개선안:**
1. **주유소 카테고리 추가**
   - 카카오맵 검색어: "주유소", "SK에너지", "GS칼텍스", "현대오일뱅크", "S-OIL"
   - 시드 데이터 크롤링 (전국 주요 도시)
   - 검색 결과에 **유가 정보** 표시 (선택적, 나중에)

2. **주유소 전용 UI**
   - 이탈 거리 표시 더 강조 (운전자는 시간보다 거리 중요)
   - "왼쪽/오른쪽" 방향 표시 (경로 기준)
   - 셀프/풀서비스 구분

3. **빠른 접근**
   - 인기 경로 프리셋에 "주유소" 기본 선택
   - 첫 화면 카테고리 칩에서 상단 노출

**우선순위:** ⭐⭐⭐⭐⭐ (실용성 = 시장 적합성)

### ✅ 구현 2: API 헬스체크 엔드포인트 (E)

**목표:** Railway 배포 안정성 + 에러 조기 감지

**구현:**

1. **헬스체크 API** (`src/app/api/health/route.ts`)
   ```typescript
   export async function GET() {
     try {
       // 1. 데이터베이스 연결 체크
       const dbCheck = await prisma.$queryRaw`SELECT 1`;
       
       // 2. 카카오맵 API 토큰 유효성 체크
       const apiCheck = await fetch('https://dapi.kakao.com/v2/local/search/keyword.json?query=test', {
         headers: {
           'Authorization': `KakaoAK ${process.env.KAKAO_REST_API_KEY}`
         }
       });
       
       if (!apiCheck.ok) {
         throw new Error('Kakao API token invalid');
       }
       
       return Response.json({
         status: 'healthy',
         timestamp: new Date().toISOString(),
         checks: {
           database: 'ok',
           kakaoApi: 'ok'
         }
       });
     } catch (error) {
       return Response.json({
         status: 'unhealthy',
         error: error.message
       }, { status: 500 });
     }
   }
   ```
