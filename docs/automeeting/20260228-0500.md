## 구현 내용

### 1. 이탈 비교 바 수치 보강 (14점)

**위치**: `ResultList.tsx` — 이탈 비교 progress bar 섹션 (~line 1325)

**변경**:
- `deltaSec = result.detourCost.duration - minDetourDuration` 계산
- `isBest = deltaSec < 30` (30초 이내 = 사실상 동일)
- 레이블: `isBest ? '⭐최단' : '+${deltaMin}분 더'`
- 텍스트 너비: `w-6` → `min-w-[44px]` (긴 텍스트 대응)
- 바 로직: IIFE `(() => {...})()` 패턴으로 로컬 변수 정리

**효과**:
- 사용자가 "2위는 1위보다 +3분 더 걸린다"를 즉시 파악
- "보통" 같은 추상적 레이블 제거 → 구체적 정보 제공

```tsx
// Before
'최소' | '보통' | '높음'

// After
'⭐최단' | '+3분 더' | '+7분 더'
```

### 2. selectedId → 리스트 카드 스크롤 동기화 (13점)

**위치**: `ResultList.tsx` — 포커스 스크롤 useEffect 바로 뒤 (~line 551)

**구현**:
```tsx
useEffect(() => {
  if (!selectedId || filteredResults.length === 0) return;
  const idx = filteredResults.findIndex((r) => r.place.id === selectedId);
  if (idx === -1) return;
  const timer = setTimeout(() => {
    const item = document.querySelector(`[data-result-index="${idx}"]`);
    if (item) item.scrollIntoView({ block: 'nearest', behavior: 'smooth' });
  }, 350); // BottomSheet 애니메이션 후 스크롤
  return () => clearTimeout(timer);
}, [selectedId]);
```

**효과**:
- 지도 마커 클릭 후 BottomSheet 올리면 선택된 카드가 뷰에 보임
- 350ms 딜레이로 BottomSheet 슬라이드 애니메이션 완료 후 스크롤
- filteredResults 기준으로 인덱스 찾아 data-result-index와 일치
