## 2. UX/UI 개선점 분석

### 2.1 사용자 여정 분석

#### 현재 플로우
1. **진입** → 출발/도착 입력 → 카테고리 선택 → 검색
2. **결과** → 리스트 확인 → 상세보기 → 경로 비교
3. **액션** → 네비 연결 / 즐겨찾기 / 공유

#### 개선 포인트
- **너무 많은 단계**: 출발/도착 입력 → 카테고리 선택 → 검색 (3단계)
- **반복 입력 번거로움**: 출발지를 매번 입력해야 함
- **결과 비교 불편**: 최대 3개만 비교 가능, 시각화 부족
- **검색 실패 시 대응**: 대안 제안은 있지만 자동 재검색은 없음

### 2.2 모바일 UX 문제점
1. **검색 오버레이**: 전체화면 오버레이가 지도 탐색을 방해
2. **바텀시트**: snap 조작이 직관적이지 않음
3. **스크롤 성능**: 결과 리스트가 많으면 버벅임

### 2.3 데스크톱 UX 문제점
1. **사이드바 고정 너비**: 420px로 너무 좁음 (큰 화면에서)
2. **지도 인터랙션**: 지도 클릭 시 액션이 제한적
3. **멀티태스킹 부족**: 여러 검색을 동시에 비교할 수 없음

### B. 실시간 영업시간 필터

**구현 내용**:
```typescript
// src/lib/navigation-links.ts
export function getKakaoNaviLink(
  start: { lat: number; lng: number },
  waypoint: { lat: number; lng: number; name: string },
  end: { lat: number; lng: number }
): string {
  // 카카오내비 딥링크 생성
  const params = new URLSearchParams({
    sp: `${start.lat},${start.lng}`,
    ep: `${end.lat},${end.lng}`,
    wp: `${waypoint.lat},${waypoint.lng}`,
    wpname: waypoint.name,
  });
  return `kakaonavi://navigate?${params}`;
}

export function getTmapLink(...) { /* 티맵 딥링크 */ }
```
