# MidWayDer Auto Meeting Review - 2026-02-25

## 📋 1단계: 프로젝트 리뷰

### UX/UI 개선점

#### 1. 경로 미리보기 정보 부재
**현상**: 출발지/도착지 입력 후 검색 전에 직통 경로 정보(거리/시간)가 표시되지 않음
**문제**: 사용자가 경유지 이탈 비용을 판단할 기준점이 없음
**개선안**: 검색 전에 "A→B 직통: 12.5km, 20분" 같은 미리보기 표시

#### 2. 로딩 상태 세분화 부족
**현상**: "찾는 중..." 메시지만 표시
**문제**: 긴 검색 시간에 사용자가 불안해함
**개선안**: "경로 분석 중..." → "경유지 검색 중..." → "결과 정렬 중..." 단계별 표시

#### 3. 즐겨찾기 관리 기능 미흡
**현상**: 즐겨찾기 추가만 가능, 삭제/수정 불가
**문제**: 잘못 추가하거나 오래된 경로 삭제 불가
**개선안**: 즐겨찾기 관리 UI (이름 수정, 삭제, 순서 변경)

#### 4. 검색 결과 없을 때 안내 부재
**현상**: 경유지를 찾을 수 없을 때 빈 화면만 표시
**문제**: 사용자가 버그인지 실제로 없는 건지 혼란
**개선안**: "이 경로에서는 OO를 찾을 수 없어요" + 대안 카테고리 제안

#### 5. 인기 경로 프리셋 과다
**현상**: 모바일 하단에 6개 프리셋 표시로 스크롤 필요
**문제**: 첫 화면 복잡도 증가
**개선안**: 3~4개로 줄이고 "더보기" 버튼 추가

#### 6. GPS 버튼 접근성
**현상**: 출발지 입력란 옆에만 GPS 버튼 존재
**문제**: 도착지를 GPS로 설정하려면 스왑 필요
**개선안**: 출발지/도착지 모두 GPS 버튼 제공 또는 "어느 쪽에 현재 위치를 설정할까요?" 다이얼로그

### 신규 기능 제안

#### 1. 경로 저장/공유 개선
**현재**: URL 파라미터만 전달, 이름 없음
**제안**:
- 경로에 사용자 정의 이름 부여 ("회사→집 퇴근길")
- SNS 공유 시 OG 이미지 자동 생성 (지도 캡처)
- 짧은 URL 생성 (short link service)

#### 2. A/B 경로 비교 UI
**현재**: 단일 경로만 표시
**제안**:
- 최단거리/최단시간 두 경로를 지도에 동시 표시
- 색상 구분 (파란색/초록색)
- 거리/시간/통행료 차이 비교 테이블

#### 3. 실시간 교통 정보 반영
**현재**: 정적 경로 계산
**제안**:
- Naver/Kakao 실시간 교통 API 연동
- "지금 출발하면 +5분" 같은 실시간 정보
- 혼잡도 색상 표시 (빨강/주황/녹색)

#### 4. 멀티 경유지 조합
**현재**: 단일 카테고리만 검색
**제안**:
- "커피 + 편의점" 같은 조합 검색
- 두 경유지를 모두 들르는 최적 순서 계산
- "A→C1→C2→B" 경로 추천

#### 5. 오프라인 모드
**현재**: 네트워크 없으면 사용 불가
**제안**:
- 최근 검색 결과 IndexedDB에 캐싱
- 지도 타일 캐싱 (PWA Service Worker)
- "오프라인 모드: 최근 결과 표시" 안내

#### 6. 음성 입력
**현재**: 텍스트 타이핑만 가능
**제안**:
- Web Speech API 활용
- "강남역"처럼 짧은 입력도 음성으로
- 운전 중 핸즈프리 입력 지원

### 경쟁력 분석

#### 강점
1. **Detour Cost 알고리즘**: 실제 도로 이탈 거리/시간 정확 계산
2. **PostGIS 공간 쿼리**: 경로 주변 필터링 성능 (< 200ms)
3. **실제 도로 반영**: 중앙분리대, 유턴, 일방통행 자동 고려
4. **깔끔한 UI**: 네이버지도 스타일 파스텔톤, 직관적 인터페이스

#### 약점
1. **실시간 교통 미반영**: 카카오내비/티맵은 실시간 소요시간 제공
2. **단일 경유지만 지원**: 경쟁사는 최대 5개 경유지 가능
3. **매장 데이터 신선도**: 크롤링 기반, 폐업/이전 정보 업데이트 지연
4. **카카오맵 의존성**: Naver API로 전환 시 리스크

#### 차별화 포인트
- **"경로 중간에 들르기" 특화**: 일반 지도는 "주변 검색"만 제공
- **이탈 비용 최소화**: "+450m, +2분" 같은 정확한 정보
- **경로 기반 추천**: 직선거리가 아닌 실제 경로상 근접도

### 데이터 활용 인사이트

#### 현재 수집 중인 데이터
- 검색 로그: 출발지, 도착지, 카테고리, 타임스탬프
- 클릭 로그: 선택된 경유지, 순위
- 최근 검색: 로컬 스토리지

#### 활용 방안
1. **인기 경로 자동 감지**
   - 30일간 검색 빈도 top 10 → 프리셋 자동 업데이트
   - 지역별 인기 경로 (강남권, 서울 외곽 등)

2. **추천 경유지 학습**
   - "강남→홍대 경로에서 80%가 선택한 스타벅스 강남점"
   - ML 모델로 finalScore 가중치 최적화

3. **시간대별 패턴**
   - 평일 오전 7~9시: 편의점 검색 많음
   - 주말 오후: 카페 검색 많음
   - 시간대별 추천 카테고리 표시

4. **카테고리 선호도**
   - 20대: 카페 > 편의점
   - 30대: 다이소 > 올리브영
   - 타겟 광고 소재 개인화
