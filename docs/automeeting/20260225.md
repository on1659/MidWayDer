## 🎯 UX/UI 개선점

### 1. **정렬/필터 기능 부족**
**현재 문제:**
- 검색 결과가 종합 점수순으로만 정렬
- 사용자가 "가장 가까운 곳" 또는 "가장 빠른 곳"으로 정렬 불가
- 영업시간, 리뷰 평점 같은 추가 필터 없음

**개선안:**
- 정렬 옵션 추가: 종합 점수(기본) / 이탈 거리 / 이탈 시간
- 필터 옵션: 영업중만 보기, 평점 4.0 이상 등
- UI: 결과 목록 상단에 드롭다운 or 칩 형태

**사용자 가치:** 빠르게 원하는 조건의 경유지 찾기

---

### 2. **경로 비교 어려움**
**현재 문제:**
- 한 번에 하나의 경유지만 지도에 표시
- 여러 후보를 비교하려면 반복 클릭 필요
- 이탈 거리/시간을 시각적으로 비교하기 어려움

**개선안:**
- "비교 모드" 추가: 최대 3개 경유지 선택
- 선택한 경유지들의 경로를 반투명 선으로 동시 표시
- 테이블 형태로 이탈 거리/시간 나란히 비교

**사용자 가치:** 의사결정 속도 향상

---

### 3. **장소 상세정보 부족**
**현재 문제:**
- 이름, 주소, 전화번호, 카테고리만 표시
- 영업시간, 주차 정보, 리뷰 없음
- "지금 영업 중인지" 알 수 없음

**개선안:**
- 카카오 Place API로 추가 정보 가져오기
  - 영업시간 (현재 영업 여부 표시)
  - 주차 가능 여부
  - 리뷰 평점 + 최근 리뷰 1~2개
  - 대표 사진

**사용자 가치:** 더 정확한 경유지 선택

---

### 4. **다중 경유지 미지원**
**현재 문제:**
- A → C → B만 가능
- 실생활에서는 "은행 갔다가 우체국 가는 길에 카페"처럼 2~3곳 들르는 경우 많음

**개선안:**
- 경유지 추가 버튼: "다른 곳도 들를래요"
- A → C1 → C2 → B 경로 계산
- 순서 최적화 (TSP 간단 휴리스틱)

**사용자 가치:** 심부름/업무 여러 개 한 번에 처리

---

### 5. **지도 스크린샷 공유**
**현재 문제:**
- 공유 시 URL만 전송
- 카카오톡 등에서 미리보기 없음
- 친구에게 "여기 어때?"하고 보여주기 어려움

**개선안:**
- 공유 버튼 클릭 시 경로를 canvas에 렌더링
- PNG 이미지로 생성 후 클립보드 복사 or 다운로드
- Open Graph 메타 태그 동적 생성 (og:image)

**사용자 가치:** 소셜 공유 활성화

---

### 6. **자주 가는 경로 추천**
**현재 문제:**
- 즐겨찾기는 수동 저장
- "매주 월요일 회사 가는 길에 들르는 카페" 같은 패턴 인식 없음

**개선안:**
- 최근 검색 기록 분석 (3회 이상 반복 → 자동 제안)
- "매주 반복되는 경로네요. 즐겨찾기에 추가할까요?" 알림
- 요일/시간대별 추천 (월요일 아침 → 커피, 금요일 저녁 → 편의점)

**사용자 가치:** 개인화된 경험

---

### 7. **실시간 교통 정보 표시**
**현재 문제:**
- 네이버 Directions API는 실시간 교통 반영하지만 UI에 표시 없음
- "지금 이 경로가 막히는지" 알 수 없음

**개선안:**
- 경로선 색상 변경: 초록(원활) / 주황(지체) / 빨강(정체)
- "현재 교통상황" 아이콘 + 툴팁
- 예상 도착 시간 범위 (20~25분)

**사용자 가치:** 실시간 상황 반영

---

### 8. **오프라인 모드**
**현재 문제:**
- PWA지만 네트워크 없으면 동작 안 함
- 터널/지하 진입 시 재검색 불가

**개선안:**
- Service Worker로 최근 검색 결과 캐싱
- IndexedDB에 경로 데이터 저장
- 오프라인 시 "이전 결과 보기" 제공

**사용자 가치:** 안정성 향상

## 💡 추가 인사이트

### 비즈니스 방향성
- **B2C → B2B 확장 가능성**
  - 배달 기사, 택배 기사용 최적 경로
  - 영업사원 동선 최적화
  - API 제공 (detour-as-a-service)

### 데이터 활용
- **사용 패턴 분석**
  - 어떤 카테고리가 인기?
  - 어떤 시간대에 많이 검색?
  - 평균 이탈 허용 범위는?
- **장소 추천 알고리즘 개선**
  - 사용자 피드백 수집 (별점, 리뷰)
  - 머신러닝으로 선호도 학습

### 경쟁력 분석
- **카카오맵/네이버지도**
  - 경유지 검색 없음 (수동 추가만 가능)
  - MidWayDer의 Detour Cost 알고리즘이 차별화 포인트
- **Google Maps**
  - "Add stop" 기능 있지만 자동 추천 없음
  - 한국 지도 정확도 낮음

**결론:** Detour Cost + 자동 추천이 핵심 경쟁력. 여기에 실시간 정보(영업시간, 교통)를 더하면 확실한 차별화 가능.

## 🔄 기술 부채

### 현재 알려진 이슈
1. **카카오맵 vs 네이버맵 혼용**
   - 프론트: 카카오맵
   - 백엔드: 네이버 API
   - 경로 데이터 변환 오버헤드
   - **해결책:** 네이버맵 SDK로 통일 or 카카오맵 Directions API 사용 검토

2. **PostGIS 쿼리 최적화**
   - 현재 1km 버퍼 → 일부 결과 누락 가능
   - 동적 버퍼 크기 조정 필요 (경로 길이에 비례)

3. **Railway PostgreSQL 용량**
   - 무료 플랜 500MB 제한
   - 매장 데이터 증가 시 대응 필요

### 리팩토링 후보
- `page.tsx` 파일 크기 (600줄) → 커스텀 훅 분리
- API route 에러 처리 통일
- 타입 정의 중복 제거
