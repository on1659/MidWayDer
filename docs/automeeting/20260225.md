4. **검색 템플릿**: "출근길", "퇴근길", "드라이브" 등 시간대별 프리셋

**현재 상태:**
- 파스텔톤 카드형 결과 리스트
- 이탈 거리/시간 뱃지
- 경로 타입 필터, 정렬 옵션
- 지도에 경로 + 마커 표시

**개선 포인트:**
1. **사진/리뷰 정보**: 네이버/카카오 API에서 이미지 썸네일 + 별점 표시
2. **경유지 여러 개 선택**: 체크박스로 2-5개 선택 → 최적 순서 자동 계산
3. **실시간 혼잡도**: 시간대별 예상 소요 시간 (출퇴근 시간 반영)
4. **AR 뷰**: 스마트폰 카메라로 경로상 경유지 AR 오버레이

#### 📱 결과 활용/공유
**현재 상태:**
- 링크 공유 (URL params)
- 즐겨찾기 저장

**개선 포인트:**

4. **커뮤니티 리뷰**: 경유지 방문 후 "이 추천이 도움됐어요" 리뷰 작성

### B. 신규 기능 제안

#### 🚀 고도화 기능
1. **멀티 스톱 최적화** (TSP Solver)
   - 사용자가 A→B→C→D 입력 시 최적 순서 계산
   - 예: "강남역 → 다이소 → 스타벅스 → 판교역" 자동 순서 조정
   - 알고리즘: Greedy 또는 간단한 DP (5개 이하면 충분히 빠름)

2. **시간대별 스마트 추천**
   - 출퇴근 시간(7-9시, 18-20시): 빠른 경유지 우선
   - 점심 시간(12-13시): 식당 카테고리 자동 제안
   - 주말 오후: 카페/디저트 우선 추천

3. **AI 추천 엔진** (누적 데이터 활용)
   - ClickLog 분석: "이 경로에서 사람들이 가장 많이 선택한 경유지"
   - 개인화: 내가 자주 가는 카테고리 학습 (스타벅스 vs 이디야)
   - "비슷한 경로를 검색한 사람들은 이것도 봤어요"

4. **오프라인 모드** (PWA 고도화)
   - 자주 가는 경로 + 경유지 데이터 IndexedDB 캐싱
   - 네트워크 없어도 최근 검색 재확인 가능
   - Service Worker로 API 응답 캐싱 (30분 TTL)

5. **B2B API** (배달/물류 업체용)
   - REST API: `POST /api/optimize-route` (다중 경유지 최적화)
   - 요금제: 월 100회 무료, 이후 건당 ₩100
   - 대시보드: 검색 통계, API 사용량 확인

#### 💡 사용성 개선
1. **검색 자동완성 개선**
   - 현재: 네이버/카카오 API 자동완성
   - 개선: 내 검색 히스토리 우선 표시 ("강남역" 입력 시 이전 검색 "강남역 2번 출구" 자동 제안)

2. **경로 비교 모드 강화**
   - 현재: 상위 3개 경유지 비교
   - 개선: 사용자가 직접 2-5개 선택해서 나란히 비교 (표 형식)

3. **알림 설정**
   - "집 근처 1km 이내 도착 시 다이소 추천 알림"
   - "출근 시간 30분 전에 즐겨찾는 경로 검색 자동 실행"

### C. 경쟁력 분석

#### 🏆 현재 강점
- **명확한 니치**: "가는 길에 들를 곳"에 특화
- **정확한 이탈 비용**: 네이버/카카오는 직선거리만 보여줌, MidWayDer는 실제 경로 이탈 계산
- **빠른 성능**: 3초 이내 응답
- **깔끔한 UI**: 네이버지도 스타일 + 파스텔톤으로 차별화

#### ⚠️ 약점
- **카테고리 제한**: 네이버/카카오 Local API에 의존 → 세분화된 검색 어려움
- **실시간 정보 부족**: 영업 시간, 재고 정보 없음
- **사용자 데이터 부족**: 신규 서비스라 리뷰/평점 축적 안 됨

#### 🎯 차별화 전략
1. **커뮤니티 중심**: 사용자 리뷰/사진으로 신뢰도 확보
2. **멀티 스톱 최적화**: 경쟁사에 없는 기능 (장보기 루트)
3. **B2B 피봇**: 배달/물류 업체에 API 판매

### D. 데이터 활용 인사이트

#### 📈 현재 수집 중인 데이터
```prisma
- Place: 경유지 정보 (위치, 카테고리, 클릭수)
- SearchLog: 검색 기록 (출발/도착, 카테고리, 결과 수)
- ClickLog: 클릭 로그 (순위, 타임스탬프)
- SearchFeedback: 검색 피드백 (helpful/not)
- VisitFeedback: 방문 후기 (평점, 코멘트)
```

#### 💎 활용 아이디어
1. **인기 경로 자동 발굴**
   - SearchLog 집계: 같은 출발/도착 조합 10회 이상 → "인기 경로"로 표시
   - 프리셋 자동 생성: 주간 집계 후 인기 Top 10을 홈 화면에 노출

2. **클릭 순위 학습**
   - ClickLog 분석: 1위 경유지가 클릭 안 되고 3위가 많이 클릭됨 → 알고리즘 개선
   - A/B 테스트: 정렬 기준 변경 후 클릭률 비교

3. **시간대별 패턴**
   - timestamp 분석: 오전/오후/저녁 검색 패턴 다름
   - 출퇴근 시간(7-9시): 편의점, 카페 검색 많음 → 자동 제안

4. **카테고리 확장 우선순위**
   - SearchLog에서 결과 0개인 카테고리 집계 → 데이터 보강 우선순위
   - 예: "약국" 검색 많지만 데이터 없음 → 크롤링 우선

5. **개인화 추천**
   - sessionId 기반: 사용자별 자주 검색하는 카테고리 학습
   - "당신은 스타벅스를 자주 찾으시네요! 경로상 스타벅스를 우선 보여드릴게요"

## ⚙️ 3단계: 실제 구현 (1-2개)

### 🚀 구현 1: 멀티 스톱 최적화 (Multi-Stop Route Optimization)

#### 목표
- 사용자가 경유지를 2-5개 선택하면 최적 순서를 자동 계산
- 예: A→(다이소, 스타벅스, 편의점)→B → A→다이소→편의점→스타벅스→B

#### 알고리즘
- **Greedy Nearest Neighbor**: 현재 위치에서 가장 가까운 미방문 경유지 선택
- 5개 이하면 O(n!) brute force도 가능하지만, Greedy가 더 빠름

#### 구현 계획
1. ResultList에 체크박스 추가
2. "경로 최적화" 버튼 → API 호출
3. `/api/optimize-route` 엔드포인트 생성
4. 최적 순서 + 총 이탈 비용 계산 후 지도에 표시

**예상 소요 시간**: 1-2시간
