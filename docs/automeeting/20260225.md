# MidWayDer 자동 미팅 리뷰 - 2026년 2월 25일

## 📋 1단계: 프로젝트 리뷰

### A. UX/UI 개선점 (사용자 여정 분석)

#### 1. 초기 진입 경험
- ✅ **스플래시 스크린** → 브랜딩 효과 좋음
- ⚠️ **빈 화면 문제** → 스플래시 후 사용자가 뭘 해야 할지 모를 수 있음
- ✅ **모바일 퀵 카테고리** → 좋은 UX
- ❌ **데스크톱 퀵 카테고리 누락** → 데스크톱 사용자 불편 **(구현 완료)**

#### 2. 검색 플로우
- 현재: 출발지 → 도착지 → 카테고리 → 검색 (3단계)
- 개선 가능: 출발지만 입력하면 "주변 추천" 제공
- GPS 버튼이 출발지에만 적용 → 도착지도 필요할 수 있음

#### 3. 결과 확인
- 모바일: 결과 리스트 ↔ 지도 전환이 바텀시트로 잘 구현됨
- 데스크톱: 사이드바 + 지도 동시 표시 → 효율적
- 경유지 상세: PlaceDetail이 지도를 가리지만, 모바일에서는 불가피

#### 4. 네비게이션 연결
- ✅ **카카오맵 딥링크** 이미 구현됨
- 개선 가능: 네이버맵, 티맵 옵션 추가

#### 5. 저장/북마크
- ❌ **즐겨찾기 기능 없음** → 자주 가는 경로 재입력 불편 **(구현 완료)**
- ✅ 최근 검색 기능 있음 (삭제 가능)

### B. 신규 기능 제안

| 번호 | 기능 | 설명 |
|------|------|------|
| 1 | 즐겨찾기 경로 | 자주 가는 경로 저장 (집→회사 등) **(구현 완료)** |
| 2 | 네비 연결 확장 | 네이버맵, 티맵 딥링크 추가 |
| 3 | 다중 카테고리 검색 | 한 번에 여러 카테고리 (카페+편의점) |
| 4 | 필터링 | 영업시간, 주차가능, 24시간 등 |
| 5 | 경로 비교 UI | 여러 경유지 조합 비교 |
| 6 | 음성 입력 | Web Speech API로 주소 입력 |
| 7 | PWA 오프라인 캐시 | 최근 검색 결과 캐싱 |
| 8 | 공유 개선 | 카카오톡 공유, 이미지 공유 |
| 9 | 통계 대시보드 | 많이 검색된 경유지 순위 |
| 10 | 알림 시스템 | 목적지 근처 도착 시 경유지 추천 푸시 |

### C. 경쟁력 분석

**차별점:**
- ✅ Detour Cost 알고리즘 (실제 도로 거리/시간 기반)
- ✅ PostGIS 공간 쿼리 (정확한 경로 주변 필터링)
- ✅ 3단계 필터링 (API 호출 98% 절감)

**약점:**
- ❌ 카테고리 제한 (다이소, 스타벅스 등 소수)
- ❌ 네비 연동 단일 (카카오맵만)
- ❌ 사용자 데이터 미수집 (검색 로그, 클릭률)

**경쟁사:**
- 카카오맵 길찾기: 경유지 1개만 수동 추가 가능
- 네이버맵: 경유지 수동 추가, 자동 추천 없음
- **기회**: 멀티 경유지 자동 최적화 + 카테고리 확장

### D. 데이터 활용 인사이트

**현재 상태:**
- Place 모델만 존재 (매장 정보)
- 사용자 행동 데이터 미수집

**개선 방향:**
1. SearchLog 모델 추가 → 인기 경로/카테고리 분석
2. ClickLog 모델 → CTR 분석, 추천 알고리즘 개선
3. 시간대별/지역별 인기 경유지 통계
4. A/B 테스트 기반 UX 최적화

### E. 비즈니스 방향성

**현재:** 무료 유틸리티 앱

**수익화 방안:**
1. **광고 수익** - 매장 프로모션 (스타벅스 신메뉴 등)
2. **제휴 수수료** - 경유지 방문 시 쿠폰 제공
3. **프리미엄 플랜** - 무제한 검색, 고급 필터, 통계
4. **B2B API** - 물류/배달 경로 최적화 API 판매

**현재:** 카카오맵 딥링크만 지원

**개선:**
