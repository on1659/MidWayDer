## 4. 구현

### ① 카드 이탈비용 컬러 스트라이프

**파일:** `src/components/search/ResultList.tsx`

**변경 내용:**
- 카드 맵 콜백에 `detourRatio`, `stripeColor` 변수 추가
  ```tsx
  const detourRatio = detourRange > 30
    ? (result.detourCost.duration - minDetourDuration) / detourRange
    : 0;
  const stripeColor = detourRatio < 0.3 ? '#22c55e' : detourRatio < 0.65 ? '#f59e0b' : '#f97316';
  ```
- 카드 wrapper div 내부 첫 자식으로 4px absolute 바 삽입:
  ```jsx
  <div
    className="absolute left-0 top-0 bottom-0 z-[1] rounded-l-2xl pointer-events-none"
    style={{ width: 4, background: stripeColor }}
    aria-hidden="true"
  />
  ```
- `detourRange === 0` (모두 동일 이탈) → ratio = 0 → 모두 초록 (정상 처리)
- `detourRange <= 30` (차이 미미) → 스트라이프 표시 안 함

### ② 모바일 하단 고정 미니 요약 바

**파일:** `src/components/search/ResultList.tsx`

**변경 내용:**
1. 상태 추가:
   ```tsx
   const [showStickyBar, setShowStickyBar] = useState(false);
   const summaryHeaderRef = useRef<HTMLDivElement>(null);
   ```
2. 결과 초기화 effect에 `setShowStickyBar(false)` 추가 (새 검색 시 리셋)
3. IntersectionObserver effect 추가:
   ```tsx
   useEffect(() => {
     const el = summaryHeaderRef.current;
     if (!el) return;
     const observer = new IntersectionObserver(
       ([entry]) => setShowStickyBar(!entry.isIntersecting),
       { threshold: 0 }
     );
     observer.observe(el);
     return () => observer.disconnect();
   }, [hasResults]);
   ```
4. 요약 헤더 div에 `ref={summaryHeaderRef}` 추가
5. BottomSheet 바로 앞에 sticky 미니 바 삽입:
   - `position: sticky; bottom: 0; z-index: 10`
   - 베스트픽 이름 + "+N분 · +N.Nkm" + "🚀 바로 출발" 버튼
   - 배경: `linear-gradient(135deg, var(--bg-surface), var(--blue-50))`

## 5. 검증

- TypeScript 컴파일: `npx tsc --noEmit` → **오류 없음**
- 스트라이프: `overflow-hidden` 카드 래퍼가 좌측 바 클리핑 처리
- 스트라이프 z-index: z-[1] (스와이프 힌트 z-index 미지정보다 낮게 유지)
- sticky 동작: BottomSheet의 `overflow-y: auto` 스크롤 컨테이너 내에서 정상 작동
- BottomSheet `transform: translateY()` → fixed 포지셔닝 대신 sticky 사용 (transform 영향 없음)
- IntersectionObserver: 결과 변경/초기화 시 `setShowStickyBar(false)`로 항상 리셋
