## 구현 (상위 2개)

### ① 스와이프 힌트 애니메이션 — ResultList.tsx

**목표:** 첫 검색 결과 로드 시 첫 번째 카드가 우→복귀→좌→복귀 순으로 흔들리며
"← 주소 복사 | 네비 →" 툴팁을 1.2초간 표시. localStorage `swipe-hint-shown` 플래그로 1회만.

**변경 내용:**
- `swipeHintId: string | null`, `swipeHintDeltaX: number` 두 state 추가
- `useEffect([results])` — localStorage 미설정 시 t=0.9s부터 애니메이션 시작, t=2.1s에 완료+플래그 저장
- 카드 렌더링에서 `isHinting` 체크 → `swipeHintDeltaX` 우선 적용 (기존 스와이프와 분리)
- `transition: 0.35s ease` (기존 0.2s → 더 부드럽게)
- `isHinting && <툴팁>` 오버레이 (하단 중앙, 반투명 다크 pill)

### ② SearchOverlay 시간대 카테고리 배너 — SearchOverlay.tsx

**목표:** "어디 들를까요?" 레이블 위에 현재 시간대 기반 2개 카테고리 칩 표시.
기존 `getTimeBasedCategoryHints()` import 후 IIFE로 렌더링.

**변경 내용:**
- `import { getTimeBasedCategoryHints } from '@/lib/smart-category'` 추가
- Category chips 섹션 상단에 `지금은?` 레이블 + 2개 칩 렌더링
- 현재 선택된 카테고리와 일치 시 accent 강조
- `title={hint.reason}` 툴팁으로 이유 표시 (예: "출근 전 모닝 커피")
