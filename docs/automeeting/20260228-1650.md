## UX/UI 분석

### 발견된 문제점

1. **새로고침 후 결과 손실** — 검색 결과가 sessionStorage에 저장되지 않아 새로고침/탭 이동 후 빈 화면 복귀. 사용자가 결과를 공유 링크로 받지 않은 경우 다시 검색해야 함.
2. **정렬 옵션 부족** — 현재 추천순/거리순/시간순 3개뿐. "지금 당장 가야 하는데 몇 시에 닫는지" 기준 정렬 없음. 카페/식당 검색 시 마감 임박 매장이 무엇인지 파악 불가.
3. **필터 칩 과다** — 칩 8개 이상으로 좁은 화면에서 wrap 발생, 카드 목록까지 스크롤 길어짐.
4. **카드 우측 버튼 7개** — 좁은 화면에서 세로로 너무 길어짐. 사용 빈도 낮은 버튼들이 항상 노출.
5. **정렬 기준이 마감 시간을 고려하지 않음** — 24시간 영업 매장과 22시 마감 매장이 동일하게 취급됨.

## 우선순위 결정

**1등 결과 세션 캐시 (30점)**
- 새로고침 또는 탭 전환 후 결과가 사라지는 것은 중대한 UX 단절
- sessionStorage + 30분 TTL로 구현 — private 모드에서도 graceful fallback
- 복원 시 "🕐 이전 검색 결과를 복원했어요" 토스트 알림

**2등 마감 임박순 정렬 (22점)**
- SortFilter 4번째 옵션 "⏰ 마감임박" 추가
- 정렬 우선순위: 24시간(-1) → 마감까지 남은 분(오름차순) → 영업종료(8888) → 정보없음(9999)

## 구현

### 1. 📦 결과 세션 캐시 (30점) ✅

**파일 변경:**

| 파일 | 변경 내용 |
|------|----------|
| `src/lib/cache/session-results.ts` | 신규 — `SessionResultsCache` 인터페이스, `saveSessionResults` / `loadSessionResults` / `clearSessionResults` |
| `src/store/search-store.ts` | `restoreResults(results, totalCandidates, apiCallsUsed)` action 추가 |
| `src/app/page.tsx` | 마운트 시 복원 useEffect + 결과 변경 시 저장 useEffect |

**핵심 로직:**
```typescript
// session-results.ts
const TTL_MS = 30 * 60 * 1000; // 30분
sessionStorage.setItem('midwayder_last_search', JSON.stringify(data));

// page.tsx — 복원
useEffect(() => {
  const saved = loadSessionResults();
  if (!saved) return;
  setStart({ address: saved.startAddress, coordinates: saved.startCoords });
  setEnd({ address: saved.endAddress, coordinates: saved.endCoords });
  setCategory(saved.category);
  restoreResults(saved.results, saved.totalCandidates, saved.apiCallsUsed);
  setBottomSheetSnap('half');
  showToast('🕐 이전 검색 결과를 복원했어요', 'info');
}, []);

// page.tsx — 저장
useEffect(() => {
  if (results.length === 0 || !start?.address || !end?.address) return;
  saveSessionResults({ results, startAddress, endAddress, ... savedAt: Date.now() });
}, [results]);
```

**UX 효과:**
- 새로고침 후 자동으로 마지막 검색 결과 복원
- 30분 TTL → 오래된 결과 자동 만료
- `isCached: true` → "⚡ 캐시" 뱃지 표시로 복원 여부 명시

**정렬 로직:**
```typescript
case 'closing': {
  const getMins = (r) => {
    if (!r.place.businessHours) return 9999;
    const status = getBusinessStatus(r.place.businessHours);
    if (status.label === '24시간 영업') return -1;
    const mins = getMinutesUntilClose(r.place.businessHours);
    if (mins !== null) return mins;
    return status.isOpen ? 9999 : 8888;
  };
  return getMins(a) - getMins(b);

```

**UX 효과:**
- 카페 검색 시 "30분 후 마감" 매장이 맨 위로 → 지금 당장 가야 할 곳 파악 즉시 가능
- 24시간 영업 매장 맨 앞 (-1 score) → 시간 제약 없는 매장 먼저 제안
- 마감된 매장은 최하단 정렬
