### A. 🚗 **주유소 카테고리 - "압도적 실수요 1위" ⛽**

**현재 카테고리**: 카페, 편의점, 다이소, 올리브영, 스타벅스, 이디야  
→ 모두 **생활 편의** 중심

**문제**:
- 운전자의 **진짜 필수 경유지**는 주유소
- 주유소는 "이탈 거리/시간 민감도" 최고 (연료 바닥나면 큰일)
- 경쟁 서비스 (카카오맵, 네이버맵) 대비 **차별화 포인트**

**시장 데이터**:
- 전국 주유소: ~12,000개
- 일평균 주유소 검색: 수십만 건 (카카오맵 기준)
- "운전 중 경유지" 검색 1위 = 주유소

**개선안**:
1. **주유소 카테고리 추가**
   - 카카오맵 검색어: "주유소", "SK에너지", "GS칼텍스", "현대오일뱅크", "S-OIL"
   - 시드 데이터 크롤링 (전국 주요 도시)
   - 검색 결과에 **유가 정보** 표시 (선택적, 나중에)

2. **주유소 전용 UI**
   - 이탈 거리 표시 더 강조 (운전자는 시간보다 거리 중요)
   - "왼쪽/오른쪽" 방향 표시 (경로 기준)
   - 셀프/풀서비스 구분

3. **빠른 접근**
   - 인기 경로 프리셋에 "주유소" 기본 선택
   - 첫 화면 카테고리 칩에서 상단 노출

**우선순위:** ⭐⭐⭐⭐⭐ (실용성 = 시장 적합성)

**문제**:

- "오늘은 어디 들를까?" 반복 의사결정 피로
- 일회성 사용 → 습관 형성 실패

**개선안**:
1. **SaveRouteDialog 활성화** (이미 컴포넌트 존재!)
   - 검색 후 "경로 저장" 버튼
   - 이름 지정 ("출근길", "퇴근길" 등)
   - DB에 SavedRoute 테이블 생성

2. **빠른 접근**
   - 저장된 경로 리스트 (홈화면)
   - 원탭으로 재검색

3. **루틴 학습** (선택적, 2단계)
   - "월요일 아침마다 스타벅스 검색하셨네요"
   - 자동 제안

**우선순위:** ⭐⭐⭐⭐⭐ (리텐션 직결)
