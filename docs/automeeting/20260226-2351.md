## 1단계: UX/UI 개선점 분석 (사용자 여정 중심)

### A. 사용자 여정 — 검색 완료 직후

```
1. 3.2초 기다림 (SearchStatus 단계 표시 → 좋음 ✅)
2. 결과 10개 등장
3. 사용자: "10개... 어디 들를지 어떻게 알아?" → 카드 하나씩 보기 시작
4. 사용자: "3등이 실제론 제일 가깝네" → 정렬 기준 불신
```

**문제:** 결과 목록이 카드 10개로만 시작. "몇 개 발견했고, 얼마나 가까운지" 전체 요약이 없음.
사용자가 1번 카드만 보고 닫거나, 불필요하게 전부 스크롤해야 함.

**기회:**
- 결과 상단에 "10개 발견 • 평균 +4분 • 7개 +5분 이내" 한 줄 요약
- 스크롤 전에 가치 인지 → 검색 만족도 ↑

---

### B. 사용자 여정 — 방문 후 앱으로 돌아옴

```
1. 검색 → 결과 클릭 → PlaceDetail "방문 체크" 버튼
2. 버튼 탭 → 그냥 체크만 됨 (피드백 없음)
3. 다음 번에 같은 곳 나오면 "방문함" 표시 (localStorage)
4. 사용자: "그래서 뭐?" → 게이미피케이션 없음
```

**문제:** 방문 체크가 localStorage 기록뿐. GPS 인증 없어서 데이터 신뢰도 낮고, 사용자에게 보상이 없음.
앱의 개인화 데이터가 클릭 로그에만 의존 → 방문 완료 여부 불명확.

**기회:**
- GPS 50m 인증 → 포인트 적립 → 재방문 동기
- 서버에 VisitLog 저장 → 향후 "이 경로에서 X명 실제 방문" 데이터로 활용

### ✅ 구현 2: GPS 방문 인증 + 포인트 시스템

**파일:**
- `prisma/schema.prisma` — VisitLog, UserPoints 모델 추가
- `src/app/api/verify-visit/route.ts` — 신규 API 엔드포인트
- `src/components/place/PlaceDetail.tsx` — GPS 인증 버튼 업그레이드

**Prisma 스키마 추가:**
```prisma
model VisitLog {
  id         String   @id @default(cuid())
  placeId    String
  sessionId  String
  points     Int      @default(10)
  verifiedAt DateTime @default(now())
  place      Place    @relation(...)
  @@index([placeId])
  @@index([sessionId])
}

model UserPoints {
  id        String   @id @default(cuid())
  sessionId String   @unique
  points    Int      @default(0)
  tier      String   @default("bronze")
  updatedAt DateTime @updatedAt
}
```

**DB Push 완료:** `prisma db push` → Railway PostgreSQL 동기화 ✅

**API `/api/verify-visit` 로직:**
```
1. GPS 좌표 수신 (userLat, userLng)
2. Place.lat/lng 조회
3. Haversine 거리 계산
4. 거리 > 50m → verified: false + 거리 안내 메시지
5. 중복 인증 체크 (1시간 이내)
6. VisitLog 저장 + UserPoints upsert (increment 10)
7. Tier 재계산 (bronze/silver/gold/platinum)
8. { verified: true, points: 10, totalPoints, tier, message } 반환
```

**PlaceDetail 변경:**
- "방문 체크" (localStorage) → "방문 인증 +10P" (GPS API)
- `MapPinCheckInside` 아이콘 (pulse 애니메이션 → 인증 중)
- 인증 결과 인라인 표시 (성공/실패 메시지 + 티어 뱃지)
- 성공 시 localStorage recordVisit도 병행 저장 (오프라인 표시용)

**Before:**
```tsx
<button onClick={handleMarkVisit}>
  ✅ 방문 체크 (localStorage만)
</button>
```

**After:**
```tsx
<button onClick={handleGpsVerify}>
  📍 방문 인증 +10P
</button>
// GPS 인증 중... (pulse)
// 결과: "🎉 방문 인증 완료! +10포인트 (누적 35점)" [SILVER]
// 또는: "강남점에서 127m 떨어져 있어요 (50m 이내여야 인증 가능)"
```

**UX 효과:**
- 게이미피케이션 → 재방문 동기
- 실제 방문 데이터 → 향후 "X명 실제 방문한 곳" 뱃지 원천 데이터
- 티어 시스템 → 앱 장기 사용 유인
