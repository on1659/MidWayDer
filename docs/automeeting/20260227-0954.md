## 구현 내용 (v0.4.5)

### ① 데이터 기반 인기 카테고리 제안 [C, 13/15점]

**파일:** `src/components/search/ResultList.tsx`

**변경 내용:**
- 새 상태 `statsCategories: string[]` 추가
- `hasSearched && results.length === 0` 조건에서 `/api/stats?period=week` 비동기 호출
- SearchLog 기반 인기 카테고리 top 6 추출 (현재 카테고리 제외)
- 데이터 있으면 "🔥 이 경로에서 인기 있는 카테고리" 라벨 + 실제 데이터 표시
- API 실패/데이터 없으면 기존 하드코딩 폴백 유지 (무중단)

**UX 임팩트:**
- 사용자가 실제로 이 경로에서 다른 사람들이 많이 검색한 카테고리를 추천받음
- 개인화 + 소셜 증명 효과 → 재검색 전환율 향상 예상

### ② 즐겨찾기 저장 하단 CTA [B, 10/15점]

**파일:** `src/components/search/ResultList.tsx`, `src/app/page.tsx`

**변경 내용:**
- `ResultListProps`에 `onSaveRoute?: () => void` 추가
- 검색 결과 하단 (피드백 섹션 위)에 전체 너비 "⭐ 이 경로 즐겨찾기로 저장" 버튼 추가
  - 노란색 그라디언트 배경, 굵은 텍스트
- `page.tsx` 데스크탑/모바일 ResultList 양쪽에 `onSaveRoute={() => setSaveDialogOpen(true)}` 전달

**UX 임팩트:**
- 기존: "저장" 버튼이 데스크탑 상단 작은 텍스트, 모바일 없음
- 개선: 결과 하단에 눈에 띄는 CTA → 경로 저장률 상승 예상

### ③ keyboard nav `data-result-index` 버그 수정 [A]

**파일:** `src/components/search/ResultList.tsx`

**변경 내용:**
- 결과 카드 `<button>`에 `data-result-index={index}` 속성 추가
- 기존 `document.querySelector('[data-result-index="${focusedIndex}"]')` 로직이 이제 올바르게 작동
- 화살표 키 + Enter 키보드 접근성 완전 동작
