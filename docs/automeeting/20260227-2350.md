## 이번 구현 (2개)

### 1. ☎️ 전화 버튼 (12pt)

**배경:**
- `Place.phone` 필드가 Prisma 스키마에 존재하지만 UI에서 미활용
- 사용자가 방문 전 영업 여부를 전화로 확인하려면 주소 복사 → 검색 → 전화의 3단계 필요

**구현 내용:**
- `ResultList.tsx`에 `Phone` 아이콘 (lucide-react) import 추가
- 전체 카드 모드 우측 액션 컬럼 (⭐ 즐겨찾기, 📋 복사 아래)에 ☎️ 버튼 추가
- `result.place.phone` 있을 때만 표시 (optional rendering)
- 클릭 시: `window.open('tel:${phone}')` + `e.stopPropagation()`
- 이벤트 버블링 차단 → 카드 선택 이벤트와 충돌 없음

**코드 변경:**
```diff
// ResultList.tsx:8
- import { Copy, Check, Navigation, Clock, Zap, Star } from 'lucide-react';
+ import { Copy, Check, Navigation, Clock, Zap, Star, Phone } from 'lucide-react';

// 카드 액션 컬럼 (즐겨찾기·복사 버튼 아래)
+ {result.place.phone && (
+   <button
+     onClick={(e) => { e.stopPropagation(); window.open(`tel:${result.place.phone}`); }}
+     title={`전화: ${result.place.phone}`}
+   >
+     <Phone className="w-4 h-4" style={{ color: 'var(--green-600)' }} />
+   </button>
+ )}
```

### 2. 🏪 이 근처에도 있어요 (18pt)

**배경:**
- 사용자는 경유지 검색 후 추가로 다른 필요가 생길 수 있음 (예: 다이소 검색 후 → 편의점도 확인)
- 현재 카테고리 변경은 검색 오버레이를 다시 열어야 가능 → 마찰 高

**구현 내용:**
- `RELATED_CATEGORIES` 매핑 테이블 (19개 카테고리 → 5개 연관 카테고리)
- `getRelatedCategories(currentCategory)` 헬퍼: 직접 매칭 → 부분 문자열 매칭 → 폴백
- 결과 카드 목록 하단, 즐겨찾기 CTA 상단에 "👀 이 근처에도 있어요" 섹션 추가
- 가로 스크롤 칩 형태 (overflow-x-auto, scrollbar hidden)
- 칩 클릭 시 `onCategoryChange(cat)` 호출 → 기존 800ms 디바운스 자동 재검색 트리거

```diff

// 결과 목록 하단 새 섹션
```
