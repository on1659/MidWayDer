## 구현 내용

### 1. 경로 구간별 분포 미니 차트 (헤더 내부)
- **위치**: 결과 요약 뱃지 아래, 출발 시각 설정 위
- **로직**: `getRoutePositionLabel()` 재활용 → 5구간 카운트 배열
- **디자인**: 5컬럼 바 차트 (출발직후/초반/중간/후반/도착직전), 구간별 색상 구분
  - 출발직후: `#60a5fa` (blue), 초반: `#34d399` (green), 중간: `#a78bfa` (purple), 후반: `#f59e0b` (amber), 도착직전: `#f87171` (red)
  - 결과 없는 구간: 회색 바 (height 3px, opacity 0.35)
  - 막대 높이: `max(8, count/maxCount * 32)px` 비례 계산
  - results.length < 3이면 비표시 (chart 의미 없음)
  - 전체 구간 count = 0이면 null (경로 데이터 없는 경우)

### 2. 상위 3개 한눈에 비교 패널
- **위치**: 빠른 카테고리 칩 ↔ 빠른 필터 칩 사이
- **트리거**: "⚖️ 상위 N개 한눈에 비교 ▼ 펼치기" 토글 버튼
- **내용**: `sortedWithPins.slice(0, 3)` 기준 3컬럼 그리드
  - 각 셀: 순위 badge / 이름(truncate) / +분 / +km / 점수 pill / 영업상태(있을 때)
  - 선택된 카드: `var(--blue-200)` 배경 + accent 테두리로 강조
  - 클릭 → `handleSelect(r, i+1)` 동일 동작
- **State**: `showCompare` boolean, 결과 변경 시 false 리셋

### 3. 코드 변경
- `src/components/search/ResultList.tsx`
  - state 추가: `const [showCompare, setShowCompare] = useState(false);` (line ~218)
  - 필터 리셋 useEffect에 `setShowCompare(false)` 추가 (line ~395)
  - 헤더 내부: 분포 미니 차트 블록 추가 (결과요약 div 닫힘 직후)
  - 카테고리 칩 다음: 비교 패널 블록 추가
- TypeScript 컴파일 오류 없음 확인 (`npx tsc --noEmit`)
