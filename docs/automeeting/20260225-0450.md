### A. UX/UI 개선점 (사용자 여정 분석)

#### 1. 검색 입력 플로우
- ✅ **자동완성 기능** → 주소 입력 편리
- ✅ **GPS 버튼** → 현재 위치 빠른 입력
- ❌ **출발지/도착지 스왑 버튼 없음** → 왕복 검색 시 재입력 불편 **(우선 구현 대상)**
- ⚠️ **GPS 버튼이 출발지만 지원** → 도착지도 필요할 수 있음
- ✅ **최근 검색 기능** → 재방문 편리
- ✅ **즐겨찾기 기능** → 자주 가는 경로 저장

#### 2. 검색 결과 확인
- ✅ **경로 타입 필터** (최단거리/최단시간) → 최근 추가됨
- ❌ **검색 결과 정렬 옵션 없음** → 사용자가 원하는 기준으로 못 봄 **(우선 구현 대상)**
- ✅ **카드형 디자인** → 가독성 좋음
- ✅ **스켈레톤 로딩** → 로딩 상태 명확
- ⚠️ **경유지 선택 후 뒤로가기 어려움** → 선택 해제 버튼 필요

#### 3. 경유지 상세
- ✅ **네비 연동** (카카오맵) → 실제 이동 편리
- ⚠️ **전화번호, 영업시간 정보 부족** → 카카오 API에서 가져올 수 있음
- ❌ **경유지 방문 체크 기능 없음** → 여러 곳 들를 때 헷갈림
- ❌ **리뷰/평점 정보 없음** → 선택 근거 부족

#### 4. 경로 관리
- ✅ **공유 기능** → URL로 공유 가능
- ✅ **즐겨찾기** → 자주 가는 경로 저장
- ❌ **검색 히스토리 상세 정보 부족** → 언제 검색했는지, 선택한 경유지 정보 없음
- ❌ **경로 비교 기능 없음** → 여러 조합 비교 어려움
