## 구현 대상 (이번 세션)

### ① 체류 시간(Dwell Time) 설정 (14점) ← **핵심**

**변경 파일**: `src/components/search/ResultList.tsx`

**변경 내용**:
- `getDefaultDwellMinutes(category)` 헬퍼 — 카테고리별 기본 체류 시간 (편의점 5분, 카페 15분, 다이소 20분 등)
- `dwellMinutes` state (기본값: getDefaultDwellMinutes(currentCategory))
- `getETAText(result, baseMs, dwellMin)` — 3번째 파라미터 추가
  - `destination ETA = 출발 + toWaypoint + dwell + fromWaypoint`
- 카테고리 변경 시 dwellMinutes 자동 갱신 useEffect
- 헤더 isHeaderExpanded 섹션에 **체류 시간 설정 UI** 추가:
  - 5분/10분/15분/20분/30분 pill 버튼
  - 선택한 시간이 ETA 라벨에 "(+N분 체류)" 표시

**UX 효과**:
- 다이소 방문 예정 → 체류 20분 → 목적지 ETA = 경유지 도착 + 20분 + 이후 구간
- 체류 0분도 허용 (바로 이동 가정)

### ② 이탈 거리 필터 + 경로 근접 필터 (17점)

**변경 파일**: `src/components/search/ResultList.tsx`

**변경 내용**:
- `maxDetourKm` state (1 | 2 | 3 | null) — 이탈 거리 상한
- `proxScoreOnly` state (boolean) — proximityScore ≥ 70 필터
- `filteredResults` useMemo에 두 조건 추가
- 결과 리셋 useEffect에 두 state 포함
- 필터 초기화 버튼에 두 state 포함
- 필터 칩 UI:
  - `📏 +1km 이내` / `📏 +2km 이내` — 보라색 칩 (이탈 거리 상한)
  - `📍 경로 근접` — 청록색 칩 (proximityScore ≥ 70 기준)
- 필터 적용 중 개수 표시 조건 업데이트

**UX 효과**:
- 이탈 1km 이내만 보고 싶을 때 원탭 필터
- 경로 바로 옆 매장만 보고 싶을 때 "경로 근접" 칩 원탭
