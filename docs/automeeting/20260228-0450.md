## 구현 내용

### 1. 결과 더보기 (`search-store.ts` + `ResultList.tsx`)

**변경 파일**:
- `src/store/search-store.ts` — `maxResults: 10` → `maxResults: 20`
- `src/components/search/ResultList.tsx` — `visibleCount` state + "더 보기" 버튼

**동작**:
- 검색 시 백엔드에서 최대 20개 후보 반환 (기존 10개)
- ResultList는 처음 10개만 표시 (`visibleResults = filteredResults.slice(0, visibleCount)`)
- "결과 더 보기 (N개 남음)" 버튼 → `visibleCount = filteredResults.length` (전체 표시)
- "접기" 버튼 → `visibleCount = 10` + 리스트 상단 스크롤
- 새 검색 시 `visibleCount` 자동 10으로 리셋

**UX 영향**:
- 첫 화면에서 10개 이하의 결과로 인지 부하 감소
- 원할 때 더 많은 옵션 탐색 가능
- 필터 적용 시 "N개 (전체 M개)" 표시로 맥락 제공

### 2. Web Share / 카드 공유 강화 (`ResultList.tsx`)

**변경 파일**:
- `src/components/search/ResultList.tsx` — `handleShare` 함수 + Share2 버튼

**동작**:
- 카드 액션 컬럼 (⭐/📋/📞/✅) 에 🔗 공유 버튼 추가
- **모바일 (Web Share API 지원)**: 네이티브 공유 시트 열기
- **데스크톱/미지원**: 클립보드에 복사 후 ✅ 아이콘으로 2초 피드백
- 공유 텍스트 형식:
  ```
  📍 [장소명]
  🏠 [주소]
  ⏱ +N분 · 📏 +Nkm 이탈
  🗺 midwayder.up.railway.app
  ```

**UX 영향**:
- 카카오톡/메시지 공유 시 완전한 정보 전달
- 공유 받은 사람이 MidWayDer로 유입되는 바이럴 루프 형성
- 기존 주소 복사보다 훨씬 유용한 정보 포함
