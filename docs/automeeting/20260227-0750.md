## 1단계: 사용자 여정 기반 UX/UI 리뷰

### A. 사용자 여정 분석 🗺️

#### 시나리오 1: 카테고리 목록에 없는 걸 찾는 사용자
```
1. 앱 열기 → 출발/도착 입력
2. CategorySelect 칩 8개 훑어봄 → "세탁소"가 없음
3. "병원"도 없고 "약국"도 없고 "마트"도 없음
4. 어떻게 해야 할지 모름 → 앱 종료 💢
```

**문제점:**
- 8개 고정 칩 → 롱테일 수요(세탁소, 병원, 약국, 마트, 은행 등) 전혀 커버 못함
- "직접 검색" 방법 자체가 없음 → 이탈률 直접 연결

**개선 방향 (이번 구현):**
- "✏️ 직접 입력" 칩 추가 → 텍스트 입력으로 원하는 카테고리 검색
- localStorage에 최근 3개 저장 → 다음엔 바로 탭

---

#### 시나리오 2: 결과를 보고 "어디쯤인지" 모르는 사용자
```
1. 검색 결과 5개 → "+3분", "+5분" 등 시간 뱃지만 있음
2. "이 다이소가 경로 처음인지 끝인지 모름"
3. "출발 직전에 들러야 하나, 중간에 들러야 하나?" 판단 불가 ❌
4. 어떤 카드가 더 적합한지 결정 못 함 → 이탈 or 잘못된 선택
```

**문제점:**
- `+시간`, `+거리` 뱃지는 있는데 "경로상 어느 위치인지" 정보가 없음
- `routes.toWaypoint.distance / routes.original.distance` 데이터는 이미 있음
- 사용자는 "경로 40% 지점에서 이탈해서 다녀오는 것"이라는 맥락이 없으면 판단 어려움

**개선 방향 (이번 구현):**
- `출발 직후 / 경로 초반 / 경로 중간 / 경로 후반 / 도착 직전` 5단계 라벨
- 📍 아이콘 + 라벨을 뱃지로 카드에 추가

---

#### 시나리오 3: 즐겨찾기 경로가 없어서 매일 같은 경로를 재입력하는 사용자
```
1. 매일 "서울시청 → 강남역" 출근길에 앱 사용
2. 매번 출발지/도착지 다시 입력 → 불필요한 반복 ❌
3. RoutineBanner는 있지만, 출퇴근 시간이 아닌 낮에는 접근 불가
```

**문제점:**
- 즐겨찾기에 "경로 세트(출발+도착)"를 저장하는 기능이 없음
- 현재 즐겨찾기는 개별 장소(Place) 저장에 그침
- 루틴 외 시간에는 집/회사 설정 방법이 UI 상에 없음

**개선 방향 (다음 세션):**
- "이 경로 저장" → 경로 세트를 즐겨찾기에 추가
- 저장된 경로는 홈 화면에서 원탭 실행

---

#### 시나리오 4: 결과 카드가 너무 많은 정보로 스크롤 피로
```
1. 검색 결과 10개
2. 카드 1개당: 이름 + 주소 + 이탈거리 + 이탈시간 + 루트타입 + 인기도 + 영업상태
              + 추천뱃지 (최대 3개) + 한 줄 요약 + 위치뱃지 (신규) + 네비 버튼
3. 카드 높이 ≈ 180px → 10개 = 1800px 스크롤 필요
```

**문제점:**
- 뱃지가 계속 늘어나면서 카드가 길어짐
- 핵심 정보(이름, 이탈시간, 위치)만 원하는 사용자에게 과부하

**개선 방향 (향후):**
- 카드 접기/펼치기 또는 "핵심 3가지만 보기" 컴팩트 모드

## 4단계: 실제 구현 (이번 세션 상위 2개)

### ✅ 구현 1: 경로상 위치 표시 (ResultList.tsx)

**변경 내용:**
- `getRoutePositionLabel(result)` 헬퍼 함수 추가 (ResultList.tsx 내부)
- `routes.toWaypoint.distance / routes.original.distance` 비율로 5단계 라벨 결정
- 결과 카드 뱃지 영역에 "📍 {라벨}" 뱃지 추가

**구현 핵심:**
```typescript
function getRoutePositionLabel(result: DetourResult): string | null {
  const toWaypointDist = result.routes.toWaypoint.distance;
  const originalDist = result.routes.original.distance;
  if (!originalDist || originalDist === 0) return null;
  const progress = toWaypointDist / originalDist;
  if (progress < 0.2) return '출발 직후';
  if (progress < 0.4) return '경로 초반';
  if (progress < 0.6) return '경로 중간';
  if (progress < 0.8) return '경로 후반';
  return '도착 직전';
}

// 카드 뱃지 영역
{(() => {
  const posLabel = getRoutePositionLabel(result);
  if (!posLabel) return null;
  return (
    <span style={{ background: 'var(--purple-100)', color: 'var(--purple-700)' }}>
      📍 {posLabel}
    </span>
  );
})()}
```

**UX 효과:**
- 사용자가 "어느 시점에 이 장소를 지나는지" 직관적으로 파악
- "출발 직후"와 "도착 직전"은 다른 판단 → 더 나은 경유지 선택
