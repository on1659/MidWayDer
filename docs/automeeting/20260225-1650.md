2. **운전 모드**
   - 큰 버튼 UI
   - 음성 명령 지원 (선택적)
   - "다음", "이전" 음성 조작

3. **거리 도달 알림**
   - 경유지 200m 전: "곧 다이소 강남점입니다"
   - GPS 위치 기반 실시간 추적

**우선순위:** ⭐⭐⭐⭐ (안전성 + 접근성)
