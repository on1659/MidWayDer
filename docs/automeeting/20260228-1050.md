## 5. 구현

### Feature 1: 실시간 ETA 카운트다운

**변경 파일**: `src/components/search/ResultList.tsx`

**구현 내용**:
- `nowMs` state 추가 (`useState(Date.now())`)
- `isNowDeparture`: `|departureMs - nowMs| < 2분` 조건
- `useEffect`: `isNowDeparture`일 때 `setInterval(60000)` 실행
- `getETAText(result, isNowDeparture ? nowMs : departureMs)` 로 ETA 갱신
- 헤더 "출발 시각" → "출발 중" + 🟢 animate-pulse
- ETA 표시: 🕐 → 🟢 animate-pulse + "지금 출발 중" + "· 1분마다 갱신" 라벨

**효과**: 지금 출발 선택 시 시간이 흐름에 따라 ETA가 자동으로 업데이트됨.

### Feature 2: 영업 종료/오픈까지 남은 시간 뱃지

**변경 파일**: `src/lib/business-hours.ts`, `src/components/search/ResultList.tsx`

**business-hours.ts 추가 함수**:
- `getMinutesUntilClose(businessHours)`: 영업 중일 때 종료까지 남은 분 반환
- `getMinutesUntilOpen(businessHours)`: 마감 상태일 때 오픈까지 남은 분 반환
- 24시간/키워드 마감/파싱 불가 시 null 반환

**ResultList 변경**:
- 전체 카드: 영업 상태 뱃지를 확장
  - 마감 30분 이내: "⚠️ N분 후 마감" + amber 강조 테두리
  - 오픈 30분 이내: "🕐 N분 후 오픈" blue 뱃지 추가
- 컴팩트 카드: "⚠️{N}분" 소형 뱃지 표시

**효과**: 마감 임박 장소를 한눈에 파악, 오픈 예정 장소도 인지 가능.
