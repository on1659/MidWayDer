## 1단계: 사용자 여정 기반 UX/UI 리뷰

### A. 사용자 여정 분석 🗺️

#### 시나리오 1: 첫 검색하는 사용자 (로딩 경험)
```
1. 출발지/도착지/카테고리 입력 후 "경유지 찾기" 탭
2. 화면에 동그라미 3개 바운스 + 스켈레톤 카드 4개
3. 3~15초 대기 (API 호출 시간)
4. "뭘 하고 있는 거지? 서버가 죽은 건가? 얼마나 기다려야 하지?" ❌
5. → 조급함에 재탭 → 중복 API 호출 or 이탈
```

**문제점:**
- 로딩이 "블랙박스" — 내부 프로세스가 전혀 보이지 않음
- 단순 스피너는 "기다려" 신호만 줄 뿐 "무엇을 하고 있는지" 모름
- 예상 완료 시점을 알 수 없어 인내심이 빨리 소진됨

**개선 방향 (이번 구현):**
- 3단계 로딩 인디케이터: 🔍 경로 분석 중 → 📍 장소 탐색 중 → ⚡ 비용 계산 중
- 시간 기반 단계 전환 (2.5초, 6초)으로 진행감 시각화
- 완료된 단계는 ✅로 표시 → 진행 상황 명확히 인지

---

#### 시나리오 2: 좋은 경유지를 발견한 재방문 사용자
```
1. "서울역→강남역, 스타벅스" 검색
2. 3번 결과 "스타벅스 강남점" — 항상 이 지점을 가고 싶다
3. 현재: 매번 같은 검색 반복 → 같은 결과에서 찾아야 함
4. "이 장소만 저장하고 싶다" 버튼 없음 ❌
5. → 재방문 동기 감소, "다음엔 카카오맵 쓰지" 이탈
```

**문제점:**
- 현재 즐겨찾기는 "경로+카테고리 세트" 단위만 저장 가능
- 특정 장소 (ex. 단골 스타벅스) 를 직접 즐겨찾기할 방법 없음
- 재방문 시 매번 같은 검색을 반복해야 함 → retention 저하

**개선 방향 (이번 구현):**
- 각 결과 카드에 ⭐ 토글 버튼 추가 (컴팩트/전체 모드 모두)
- localStorage 기반으로 즉시 저장/해제
- 즐겨찾기된 장소는 골든 ⭐ 강조 표시

---

#### 시나리오 3: 데스크탑으로 검색하는 사용자 (현황 점검)
```
1. 데스크탑 사이드 패널에서 검색
2. 결과가 나오면 사이드 패널 아래 쪽에서 스크롤해야 보임
3. 컴팩트 모드 토글이 결과 영역(ResultList) 안에 있어서 찾기 어려움
4. → 스크롤 후 필터 조정이 불편 (개선 여지)
```

**문제점:**
- 컴팩트 토글이 ResultList 내부에 숨어있음 → 발견성 낮음
- (이번 세션에서는 구현 스코프 초과 → 다음 세션으로)

## 4단계: 실제 구현 (이번 세션)

### ✅ 구현 1: 로딩 단계 세분화 (ResultList.tsx)

**변경 파일:** `src/components/search/ResultList.tsx`

**변경 내용:**
- `LOADING_STAGES` 상수 추가 (컴포넌트 외부, 3단계 정의)
- `loadingStage: number` state 추가 (0~2)
- `useEffect` 타이머 추가: 2.5초→stage1, 6초→stage2, isLoading false→stage0 리셋
- 기존 "바운스 점 3개 + 스켈레톤 4개" 렌더링 → 3단계 인디케이터로 교체

**로딩 UI 구조:**
```
[🔍 경로 분석 중] ─────── [📍 장소 탐색 중] ─────── [⚡ 비용 계산 중]
       ↑ 현재 단계 강조 (scale-110 + shadow)
       ↑ 완료된 단계는 ✅ + bg-green-100

진행 바: ──────░░░░░░░░ (단계에 따라 0%, 50%, 100%)
설명 텍스트: "경로 주변 매장을 찾고 있어요" (animate-pulse)
```

**UX 효과:**
- "몇 초 걸리나?" → 단계별 진행 상황으로 예측 가능
- 완료 단계 ✅ 표시 → "작업이 실제로 진행 중임" 신뢰
- API 응답이 빠르면 (캐시 HIT 등) 단계가 빠르게 넘어가는 시각적 피드백

### ✅ 구현 2: 개별 장소 즐겨찾기 (place-favorites.ts + ResultList.tsx)

**새 파일:** `src/lib/place-favorites.ts`

**인터페이스:**
```typescript
export interface PlaceFavorite {
  placeId: string;
  placeName: string;
  category: string;
  address: string;
  lat: number;
  lng: number;
  savedAt: number;
}
```

**API:**
- `getPlaceFavorites(): PlaceFavorite[]` — localStorage에서 전체 조회
- `addPlaceFavorite(place)` — 추가 (중복 방지, 최대 20개)
- `removePlaceFavorite(placeId)` — 삭제
- `isPlaceFavorited(placeId): boolean` — 즐겨찾기 여부 확인

**ResultList.tsx 변경:**
- `favPlaces: Set<string>` state — 현재 결과 중 즐겨찾기된 ID 집합
- `useEffect` on mount — localStorage에서 초기 로드
- `handleTogglePlaceFav(e, result)` — 토글 핸들러
- 컴팩트 카드: 네비 버튼 앞에 ⭐ 버튼 추가
- 전체 카드: 주소 복사 버튼 위에 ⭐ 버튼 추가 (세로 스택)

**Star 아이콘:**
- 즐겨찾기 O: `fill="#f59e0b"`, color `--yellow-600` (골든 ⭐)
- 즐겨찾기 X: `fill="none"`, color `--text-muted` (회색 ⭐)
