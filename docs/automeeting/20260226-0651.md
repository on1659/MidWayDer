## A. UX/UI 개선점 (사용자 여정 분석)

### 사용자 여정 흐름
1. **앱 접속** → 로딩 (1초)
2. **검색 입력** → 출발/도착/카테고리 입력 (타이핑 또는 음성)
3. **결과 확인** → 10개 경유지 리스트 + 지도 표시
4. **경유지 선택** → 경로 미리보기 + 네비 연결
5. **재검색** → 카테고리만 변경하고 싶은데 처음부터 다시 입력

### 현재 문제점
1. **재검색 불편** — 카테고리만 바꾸고 싶은데 출발/도착 다시 입력해야 함
2. **검색 히스토리 부재** — 앱 재접속 시 이전 검색 사라짐
3. **캐싱 없음** — 같은 경로 재검색 시 API 호출 반복 (2.4초 소요)
4. **경유지 정보 부족** — 영업시간, 혼잡도, 주차 가능 여부 등
5. **오프라인 불가** — 네트워크 끊기면 아무것도 못 함

### 개선 제안
- ✅ **경로 히스토리 자동 복원** — 앱 재접속 시 마지막 검색 자동 로드
- ✅ **검색 캐싱** — 같은 경로 재검색 시 0.1초 이내 응답
- ⏳ **영업시간 필터** — "지금 영업 중인 곳만" 토글
- ⏳ **주차 가능 여부** — 매장별 주차장 유무 표시
- ⏳ **오프라인 모드** — Service Worker로 마지막 검색 결과 캐싱

## B. 신규 기능 제안

### 1. 경로 히스토리 자동 복원
- **설명:** 앱 재접속 시 마지막 검색 (출발/도착/카테고리/결과) 자동 로드
- **가치:** 사용자가 이어서 다른 카테고리 검색 가능, 앱 재시작 번거로움 제거
- **차별화:** 세션 연속성 강화, 재검색 경험 개선

### 2. 검색 결과 캐싱
- **설명:** LocalStorage에 최근 10개 검색 결과 캐싱 (30분 TTL)
- **가치:** 재검색 시 2.4초 → 0.1초, API 호출 절감
- **차별화:** 네트워크 약할 때도 빠른 응답

### 3. 영업시간 필터
- **설명:** "지금 영업 중인 곳만" 토글 (Kakao API 영업시간 정보 활용)
- **가치:** 헛걸음 방지, 실용성 향상
- **차별화:** 기존 앱들은 영업시간 정보가 있어도 필터로 제공 안 함

### 4. 주차 가능 여부 필터
- **설명:** 매장별 주차장 유무 표시 (Kakao API 정보 + 아이콘)
- **가치:** 차량 이용자에게 필수 정보
- **차별화:** 경유지 추천 + 주차 정보 조합

### 5. 실시간 교통정보 레이어
- **설명:** 지도에 교통 혼잡도 표시 (Naver Traffic API)
- **가치:** 이탈 시간 예측 정확도 향상
- **차별화:** 경유지 추천 + 교통정보 조합

### 6. 경유지 근처 도착 알림
- **설명:** GPS 추적 → 경유지 500m 이내 접근 시 푸시 알림
- **가치:** 운전 중 놓치지 않고 경유 가능
- **차별화:** 프로액티브 UX

```typescript
// LocalStorage 키
const LAST_SEARCH_KEY = 'midwayder_last_search';

// 마지막 검색 저장
export const saveLastSearch = (search: {
  start: Location;
  end: Location;
  category: string;
  results: DetourResult[];
  originalRoute: Route;
  timestamp: number;
}) => {
  try {
    localStorage.setItem(LAST_SEARCH_KEY, JSON.stringify(search));
  } catch (err) {
    console.error('[saveLastSearch] Error:', err);
  }
};

// 마지막 검색 불러오기
export const loadLastSearch = () => {
  try {
    const data = localStorage.getItem(LAST_SEARCH_KEY);
    if (!data) return null;

    const search = JSON.parse(data);
    const age = Date.now() - search.timestamp;

    // 30분 이내만 복원
    if (age > 30 * 60 * 1000) {
      localStorage.removeItem(LAST_SEARCH_KEY);
      return null;
    }

    return search;
  } catch (err) {
    console.error('[loadLastSearch] Error:', err);
    return null;
  }
};

// 페이지 로드 시 자동 복원 (src/app/page.tsx)
useEffect(() => {
  if (!appReady) return;

  const lastSearch = loadLastSearch();
  if (lastSearch) {
    setStart(lastSearch.start);
    setEnd(lastSearch.end);
    setCategory(lastSearch.category);
    setOriginalRoute(lastSearch.originalRoute);
    // results는 검색 store에 직접 설정
    useSearchStore.setState({ results: lastSearch.results, hasSearched: true });

    showToast('이전 검색이 복원되었어요 📂', 'info');
  }
}, [appReady]);
```

**1) 캐시 키 생성**
```typescript
// src/lib/cache/search-cache.ts
import { createHash } from 'crypto';
import type { Location } from '@/types/location';

export interface SearchCacheKey {
  start: Location;
  end: Location;
  category: string;
}

export interface SearchCacheValue {
  results: any[];
  originalRoute: any;
  totalCandidates: number;
  apiCallsUsed: number;
  timestamp: number;
}

const CACHE_KEY_PREFIX = 'midwayder_search_';
const CACHE_TTL_MS = 30 * 60 * 1000; // 30분

// 캐시 키 생성 (경로 + 카테고리 해시)
export const generateCacheKey = (key: SearchCacheKey): string => {
  const str = JSON.stringify({
    startLat: key.start.coordinates.lat.toFixed(4),
    startLng: key.start.coordinates.lng.toFixed(4),
    endLat: key.end.coordinates.lat.toFixed(4),
    endLng: key.end.coordinates.lng.toFixed(4),
    category: key.category,
  });

  const hash = createHash('md5').update(str).digest('hex').slice(0, 8);
  return `${CACHE_KEY_PREFIX}${hash}`;
};

// 캐시 저장
export const saveSearchCache = (key: SearchCacheKey, value: Omit<SearchCacheValue, 'timestamp'>) => {
  try {
    const cacheKey = generateCacheKey(key);
    const cacheValue: SearchCacheValue = {
      ...value,
      timestamp: Date.now(),
    };

    localStorage.setItem(cacheKey, JSON.stringify(cacheValue));

    // 캐시 키 목록 업데이트 (최대 10개)
    updateCacheKeyList(cacheKey);
  } catch (err) {
    console.error('[saveSearchCache] Error:', err);
  }
};

// 캐시 불러오기
export const loadSearchCache = (key: SearchCacheKey): SearchCacheValue | null => {
  try {
    const cacheKey = generateCacheKey(key);
    const data = localStorage.getItem(cacheKey);
    if (!data) return null;

    const cache: SearchCacheValue = JSON.parse(data);
    const age = Date.now() - cache.timestamp;

    // TTL 초과 시 삭제
    if (age > CACHE_TTL_MS) {
      localStorage.removeItem(cacheKey);
      return null;
    }

    return cache;
  } catch (err) {
    console.error('[loadSearchCache] Error:', err);
    return null;
  }
};

// 캐시 키 목록 관리 (최대 10개, FIFO)
const CACHE_KEY_LIST = 'midwayder_cache_keys';

const updateCacheKeyList = (newKey: string) => {
  try {
    const data = localStorage.getItem(CACHE_KEY_LIST);
    const keys: string[] = data ? JSON.parse(data) : [];

    // 중복 제거
    const filtered = keys.filter(k => k !== newKey);

    // 최신 키 추가
    filtered.push(newKey);

    // 10개 초과 시 가장 오래된 것 제거
    if (filtered.length > 10) {
      const removed = filtered.shift();
      if (removed) localStorage.removeItem(removed);
    }

    localStorage.setItem(CACHE_KEY_LIST, JSON.stringify(filtered));
  } catch (err) {
    console.error('[updateCacheKeyList] Error:', err);
  }
};

// 캐시 전체 삭제
export const clearAllSearchCache = () => {
  try {
    const data = localStorage.getItem(CACHE_KEY_LIST);
    const keys: string[] = data ? JSON.parse(data) : [];

    keys.forEach(key => localStorage.removeItem(key));
    localStorage.removeItem(CACHE_KEY_LIST);
  } catch (err) {
    console.error('[clearAllSearchCache] Error:', err);
  }
};
```

**2) API에서 캐시 체크**
```typescript
// src/app/api/search/route.ts (일부)
import { loadSearchCache, saveSearchCache } from '@/lib/cache/search-cache';

export async function POST(request: NextRequest) {
  try {
    const body = await request.json();
    const { start, end, category } = body;

    // 1. 캐시 체크
    const cached = loadSearchCache({ start, end, category });
    if (cached) {
      console.log('[API /search] Cache hit! ✅');
      return NextResponse.json({
        success: true,
        fromCache: true, // 프론트엔드에서 알림 표시 가능
        data: {
          originalRoute: cached.originalRoute,
          results: cached.results,
          totalCandidates: cached.totalCandidates,
          apiCallsUsed: cached.apiCallsUsed,
        },
      });
    }

    console.log('[API /search] Cache miss, fetching...');

    // 2. 실제 검색 수행
    const result = await performSearch(start, end, category);

    // 3. 캐시 저장
    saveSearchCache({ start, end, category }, {
      results: result.results,
      originalRoute: result.originalRoute,
      totalCandidates: result.totalCandidates,
      apiCallsUsed: result.apiCallsUsed,
    });

    return NextResponse.json({
      success: true,
      fromCache: false,
      data: result,
    });
  } catch (error) {
    // ...
  }
}
```
