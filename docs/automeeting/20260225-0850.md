## 🎯 1단계: 리뷰 (신뢰도 & 전환율 최적화)

### A. **첫 방문자 혼란 - "이게 뭐하는 앱이지?" 🚨 심각**

**현재 문제:**
- 첫 화면: 빈 지도 + "출발지/도착지 입력창"
- **사용자가 직접 써봐야 가치를 알 수 있음**
- 예시/데모 없음 → 이탈률 높을 것
- 스플래시 스크린 1.5초는 있지만 설명 없음

**벤치마크:**
- Airbnb: 첫 화면에 인기 목적지 카드
- 배달앱: "오늘의 추천", "인기 메뉴" 자동 표시
- 네이버지도: 최근 검색/즐겨찾기 먼저 보여줌

**개선안:**
1. **샘플 검색 자동 실행** (첫 방문 시)
   - "강남역 → 여의도" + "스타벅스" 자동 검색
   - 결과와 함께 "이렇게 경로 중간에 들를 곳을 찾아줘요!" 안내
   - "다른 경로 검색하기" 버튼

2. **인기 경로 프리셋**
   - "강남 → 홍대", "서울역 → 잠실", "인천공항 → 서울"
   - 원탭으로 검색 가능
   - 실제 데이터(SearchLog)로 인기 경로 표시

3. **3단계 온보딩 (첫 방문 시만)**
   - Step 1: "가는 길에 들를 곳을 찾아드려요"
   - Step 2: "이탈 거리/시간을 계산해서 최적 경유지 추천"
   - Step 3: "바로 검색해볼까요?"

**우선순위:** ⭐⭐⭐⭐⭐ (첫인상 = 생존 문제)

---

### B. **검색 결과 신뢰도 부족 - "왜 이게 1위야?"**

**현재 문제:**
- finalScore 숫자만 표시 (사용자가 이해 못 함)
- 왜 이 경유지가 좋은지 설명 없음
- 알고리즘은 정확하지만 **투명성 부족**

**개선안:**
1. **시각적 신뢰 지표**
   ```
   ✅ 원래 경로에서 450m만 벗어남
   ⏱️ 2분만 더 걸림
   👥 123명이 여기 다녀갔어요 (VisitFeedback 활용)
   ⭐ 평균 별점 4.2/5
   ```

2. **"왜 추천했나요?" 버튼**
   - 클릭 시 간단한 설명:
     - "가장 적게 돌아가는 길이에요"
     - "경로에서 가까워요 (근접도 85점)"
     - "다른 사용자들도 만족했어요"

3. **비교 모드 강화**
   - 현재 ComparePanel은 있지만 숨겨져 있음
   - 검색 결과 상단에 "상위 3개 비교하기" 버튼 눈에 띄게

**우선순위:** ⭐⭐⭐⭐ (신뢰 = 전환)

---

### C. **모바일 타이핑 마찰 - 주소 입력이 귀찮음**

**현재 문제:**
- 출발지/도착지 매번 타이핑
- 자동완성 있지만 키보드 열면 화면 절반 차지
- 특히 모바일에서 주소 입력 = 고통

**개선안:**
1. **GPS "현재 위치" 버튼 상단 노출**
   - 현재: 지도 우하단에 숨어있음
   - 개선: 출발지 입력창 옆에 "📍 현재 위치" 칩
   - 탭 한 번으로 현재 위치 설정

2. **최근 위치 퀵 선택**
   - 입력창 포커스 시 최근 검색 3개 바로 표시
   - 탭 한 번에 선택

3. **음성 입력** (선택적, 나중에)
   - 주소 대신 "홍대입구역"처럼 랜드마크 말하기
   - Web Speech API 활용

**우선순위:** ⭐⭐⭐⭐ (모바일 = 주 사용 환경)

---

### D. **실제 방문 전환 단절 - "검색만 하고 안 감"**

**현재 문제:**
- 검색 → 선택 → ??? → 방문
- 중간에 사용자가 이탈할 수 있는 지점:
  - "나중에 가야지" → 잊음
  - "어떻게 가지?" → 막막
  - 앱 종료 → 다시 안 옴

**개선안:**
1. **"경로 시작" 원탭 액션**
   - PlaceDetail에 "🚗 네비로 바로 가기" 버튼 (이미 있음)
   - 추가: "📱 카톡으로 공유" (친구와 약속)
   - 추가: "📅 캘린더에 저장" (나중에 방문)

2. **리마인더 설정**
   - "오늘 저녁에 알림 받기" 버튼
   - 푸시 알림: "오늘 예정: 강남역 스타벅스 들르기"

3. **방문 인증 인센티브**
   - 방문 후 별점 남기면 포인트 적립
   - 10포인트 = 광고 제거 1개월
   - 크라우드소싱 리뷰 수집 + 사용자 참여 유도

**우선순위:** ⭐⭐⭐ (리텐션 향상)

---

### E. **성능 체감 개선 - "빠르지만 안 빠른 느낌"**

**현재 문제:**
- 검색 소요 시간: 2~3초 (실제 빠름)
- 하지만 **로딩 중 아무것도 안 보임** → 답답함
- 스켈레톤은 있지만 단조로움

**개선안:**
1. **프로그레스 표시**
   ```
   찾는 중... (1/4) 경로 분석 중
   찾는 중... (2/4) 주변 매장 검색 중
   찾는 중... (3/4) 이탈 거리 계산 중
   찾는 중... (4/4) 결과 정렬 중
   ```

2. **Optimistic UI**
   - 검색 시작하자마자 지도에 예상 경로 흐릿하게 표시
   - 결과 카드 애니메이션 (위에서 슬라이드 인)

3. **백그라운드 프리페칭**
   - 출발지/도착지 입력 완료 시 경로 미리 조회
   - 검색 버튼 누르면 즉시 결과

**우선순위:** ⭐⭐⭐ (체감 성능 = UX)

### F. **데이터 활용 부족 - "로그만 쌓고 안 씀"**

**현재 문제:**
- SearchLog, ClickLog 쌓이기 시작했지만
- **아직 활용 안 함** (대시보드 없음)
- 인사이트 발굴 불가

**개선안:**
1. **관리자 대시보드** `/admin/analytics`
   - 인기 카테고리 TOP 10
   - 인기 경로 TOP 10
   - 평균 검색 시간, 결과 수
   - 클릭률(CTR) 분석
   - 시간대별 트래픽

2. **데이터 기반 추천 개선**
   - CTR 낮은 결과 → 알고리즘 재조정
   - 인기 경로 → 프리셋으로 추가
   - 특정 카테고리 인기 → 제휴 접촉

3. **실시간 통계 공개** (선택적)
   - "오늘 1,234건 검색됨"
   - "가장 인기 있는 경유지: 스타벅스"
   - 사회적 증거(social proof) 효과

**우선순위:** ⭐⭐⭐ (데이터 = 경쟁력)
