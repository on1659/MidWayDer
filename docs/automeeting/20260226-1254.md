- 사용자가 #1 추천 매장에 도착했더니 영업 종료 → 최악의 경험

### 🔴 Critical: `require()` 잘못 사용 (PlaceDetail.tsx)

**발견 위치:** `src/components/place/PlaceDetail.tsx:92`

```typescript
// ❌ 잘못된 코드: Next.js App Router에서 CommonJS require() 사용
const { getKakaoNaviLinkWithWaypoint } = require('@/lib/navigation-links');
```

**문제:**
- Next.js App Router (RSC/SSR 환경)에서 `require()`는 번들러가 예상치 못한 방식으로 처리할 수 있음
- 조건부 import로 코드 분할이 불가능, tree-shaking 방해
- TypeScript 타입 추론 손실

**해결:** 파일 상단에 static import로 변경

### 🟡 Medium: 키보드 네비게이션 listRef 접근 방식

**발견 위치:** `src/components/search/ResultList.tsx:146-154`

```typescript
// listRef가 div에 연결되지 않으면 이벤트 리스너가 등록 안 됨
```

**문제:**

- 접근성 향상을 위해 `document` 레벨 리스너 또는 `tabIndex` 추가 필요

```typescript
export interface CategoryHint {
  category: string;  // CategorySelect의 query 값과 일치해야 함
  emoji: string;
  label: string;
  reason: string;
}

export function getTimeBasedCategoryHints(): CategoryHint[] {
  const hour = new Date().getHours();

  if (hour >= 6 && hour < 10) {
    return [
      { category: '스타벅스', emoji: '☕', label: '스타벅스', reason: '출근 전 모닝 커피' },
      { category: '카페', emoji: '🏠', label: '카페', reason: '내 단골 카페 들르기' },
    ];
  }
  // ... 시간대별 힌트
}
```
