## 구현 내역 (이번 세션)

### ① 🐛 버그 수정: `(result as any).routeType` 제거

**파일**: `src/components/search/ResultList.tsx:1798`

**문제**: `DetourResult` 타입에 `routeType?: 'shortest' | 'fastest'`가 이미 정의되어 있음에도
`(result as any).routeType`으로 접근하여 타입 안전성 위반

**수정**:
```tsx
// Before (타입 위반)
const routeLabel = (result as any).routeType === 'shortest' ? '최단거리' : (result as any).routeType === 'fastest' ? '최단시간' : null;

// After (타입 안전)
const routeLabel = result.routeType === 'shortest' ? '최단거리' : result.routeType === 'fastest' ? '최단시간' : null;
```

### ② 📐 컴팩트 모드 아코디언 확장 (22점)

**파일**: `src/components/search/ResultList.tsx`

**문제**: 컴팩트 모드(≡ 간략)에서 카드 탭 시 지도 마커만 선택되고,
주소/ETA/네비 버튼을 볼 수 없어 결국 전체 모드로 전환해야 했음.

**구현**:

1. **state 추가**: `expandedCompactId: string | null` — 컴팩트 모드에서 확장된 카드 ID
2. **onClick 수정**:
   - 첫 탭: `setExpandedCompactId(id)` + `onSelect(result)` (지도 마커 선택 유지)
   - 두 번째 탭 (이미 확장): `handleSelect(result, rank)` (실제 선택 + 클릭 로그)
3. **확장 영역**: Fragment `<>` 로 감싸 `<div className="flex...">` + 확장 컨텐츠 표시

**확장 컨텐츠**:
- 주소 (roadAddress || address)
- ETA row (🟢/🕐 아이콘 + 경유지 도착시간 + 목적지 도착시간)
- 네비 버튼 (선호 앱명 자동 표시, 탭 시 확장 닫힘)
- "한 번 더 탭하면 선택됩니다" 힌트 텍스트

**UX 플로우**:
```
컴팩트 카드 탭 1회 → 아코디언 확장 (주소 + ETA + 네비 버튼)
확장된 카드 다시 탭   → 실제 선택 (점수/상세 기준)
네비 버튼 탭          → 네비 앱 실행 + 아코디언 닫힘
```

**results 변경 시**: `setExpandedCompactId(null)` 자동 초기화

### ③ 🎛 필터 칩 토글 (18점)

**파일**: `src/components/search/ResultList.tsx`

**문제**: 필터 칩 9개(영업상태/이탈시간×3/이탈거리×2/경로근접/미방문)가 항상 표시되어
프리셋만 사용하는 대다수 사용자에게 인지 부하가 큼.

**구현**:

1. **state 추가**: `showFilterChips: boolean` (기본 `false`)
2. **자동 펼침 useEffect**: 필터가 활성화되면 자동으로 `showFilterChips=true`
3. **results 초기화**: 새 검색 시 `setShowFilterChips(false)` 리셋
4. **프리셋 줄 재구성**: 기존 `flex-1` × 2에서 `flex-1` × 2 + `shrink-0` × 2로
   → 프리셋 2개 + 🎛 상세 버튼 + ≡/☰ 간략/자세히 버튼 한 줄에

**버튼 시각**:
- `showFilterChips=false` + 필터 없음: 회색 테두리 (비활성)
- `showFilterChips=true`: 파란 배경 (활성)
- `showFilterChips=false` + 필터 있음: accent 배경 (필터 있음 표시)

**결과**:
- 기본: `[⚡빠른 경유] [🔥당장!] [🎛▼] [≡간략]` — 깔끔한 4버튼 한 줄
- 🎛 탭 후: 9개 필터 칩 `flex-wrap` 표시
- 필터 적용 시: 🎛 버튼 자동 강조 (accent 색상)

**간략/자세히 이동**: 필터 칩 줄 → 프리셋 줄로 이동 (항상 표시 보장)
