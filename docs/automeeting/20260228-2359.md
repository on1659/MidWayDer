## 구현 대상 (이번 세션)

### ① 지도 마커 hover → 미니 팝업 (18점) ← **핵심**

**변경 파일**: `src/components/map/KakaoWaypointMarker.tsx`

**변경 내용**:
- `hoverCloseTimeoutRef` 추가 — mouseleave 300ms 딜레이 후 팝업 닫기
- `clickedOpenIdRef` 추가 — 클릭으로 열린 팝업 보호 (hover close 방지)
- `mouseenter` 이벤트: `clickedOpenIdRef === null`인 경우에만 `showInfoWindow` 호출
- `mouseleave` 이벤트: `clickedOpenIdRef !== waypoint.place.id`인 경우 300ms 후 `closeInfoWindow`
- `click` 이벤트: `clickedOpenIdRef = waypoint.place.id` 설정
- `mapClickHandler`: `clickedOpenIdRef = null` + `closeInfoWindow`
- cleanup에서 타이머 정리 + ref 초기화

**UX 효과**:
- 지도에서 마커 위에 마우스를 올리면 장소명/주소/이탈비용/점수 팝업 표시
- 클릭으로 고정된 팝업은 hover 이동 시 닫히지 않음
- 지도 다른 곳 클릭 시 팝업 닫힘 + 상태 초기화
