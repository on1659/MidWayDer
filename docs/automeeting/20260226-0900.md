## A. UX/UI 개선점 분석 (사용자 여정 중심)

### 사용자 여정 흐름
```
앱 진입 → 출발/도착 입력 → 카테고리 선택 → 검색 → 결과 탐색 → 경유지 선택 → 내비 실행
```

---

### 1. 루틴 감지 기능이 UI와 단절됨 🔗
**발견:** `src/lib/routine/detector.ts`가 완성됐지만 `page.tsx`에 import조차 없음.
**문제:** 매일 같은 시간에 앱을 여는 출퇴근 사용자가 매번 집/회사 주소를 수동 입력해야 함.
**영향:** 일일 이용 빈도 ↓, 앱 의존도 ↓, 경쟁 앱(T맵, 카카오내비) 대비 장점 미활용.

**개선 방향:**
- 평일 7-9시 → "출근 시간이에요! 집→회사 경로 입력하기" 배너 표시
- 평일 17-19시 → "퇴근 시간이에요! 회사→집 경로 입력하기" 배너 표시
- 집/회사가 둘 다 저장된 경우만 표시 (스마트 위치 기반)
- 1탭으로 출발지/도착지 자동 입력

---

### 2. 검색 결과 요약 정보 부족 📊
**발견:**
- 데스크톱: "X개 중 Y개 추천" 텍스트만 있음
- 모바일: "검색 결과 Y개 | X개 중 추천" 수준
**문제:**
- 원본 경로(기본 A→B) 정보가 결과 화면에 없어 이탈 비용의 상대적 의미를 파악하기 어려움
- 캐시 결과인지 실시간 결과인지 구분 없음
- 검색 소요 시간 피드백 없음

**개선 방향:**
- 결과 상단에 "기본 경로: X.Xkm · X분" 표시
- 캐시 결과 시 "⚡ 캐시" 뱃지 표시 (이미 `isCached` state 있음)
- 각 카드의 "+Xkm" 이탈 비용이 전체 경로 대비 몇 %인지 체감 가능해짐

---

### 3. 결과 없음 화면의 카테고리 버튼 탭 영역 부족 📱
**발견:** 결과 없을 때 대안 카테고리 버튼이 `px-4 py-2` 사이즈로 작음.
**문제:** 모바일에서 엄지손가락으로 탭하기 어려움 (권장 최소 44x44px 미충족).
**개선 방향:** 버튼 패딩을 `px-5 py-3`으로, 폰트를 `text-sm`에서 `text-base`로.

---

### 4. PlaceDetail 확정 후 피드백 흐름 불명확 🔄
**발견:** "경유지로 확정" 버튼 클릭 시 바텀시트가 닫히고 지도에 경로가 표시되지만
UI에서 "확정됐다"는 명확한 시각적 피드백이 없음.
**문제:** 사용자가 뭔가 완료됐는지, 다음 단계가 뭔지 파악하기 어려움.
**개선 방향:**
- 확정 후 "경유지 확정됨! ✅" 토스트 메시지
- 지도 위에 선택된 경유지 마커가 강조되는 애니메이션

---

### 5. 음성 검색 발견 가능성 낮음 🎙️
**발견:** 음성 검색 버튼이 SearchOverlay 헤더 오른쪽에 작게 있음.
**문제:** 처음 이용 사용자는 존재 자체를 모름. 탐색 오버레이 열기 전에는 접근 불가.
**개선 방향:**
- 모바일 검색 바에 마이크 아이콘 직접 노출
- 또는 온보딩 첫 방문 시 음성 검색 힌트 툴팁

## C. 우선순위 구현 (이번 세션)

### Feature 1: 루틴 경로 배너 (RoutineBanner)

**컴포넌트:** `src/components/search/RoutineBanner.tsx`
**핵심 로직:**
```
현재 시간 감지 → detectRoutine() 호출
↓
getSavedLocationByLabel('home') + getSavedLocationByLabel('work') 조회
↓
출근 시간(7-9시) + 집/회사 저장됨 → 배너 표시
퇴근 시간(17-19시) + 집/회사 저장됨 → 배너 표시
↓
탭 시: setStart(home/work), setEnd(work/home) 자동 입력
↓
markRoutinePromptShown() → 4시간 내 재표시 방지
```

**UI 배치:**
- 데스크톱: 사이드바 결과 영역 최상단 (즐겨찾기 위)
- 모바일: 하단 퀵바 최상단 (앱 소개 위)

**세션 기반 동작:**
- 4시간 내 같은 루틴 재표시 없음 (localStorage 기반)
- 집/회사가 미저장 시 배너 비표시

---

### Feature 2: 결과 요약 헤더 강화 (Result Summary Enhancement)

**변경 위치:**
- `src/app/page.tsx` - 데스크톱 결과 요약 섹션 (line ~560)
- `src/app/page.tsx` - 모바일 바텀시트 결과 헤더 (line ~867)

**추가 정보:**
```
기본 경로: X.Xkm · X분   [⚡ 캐시] (캐시 결과일 때만)
총 X개 후보 중 Y개 추천
```

**데이터 소스:**
