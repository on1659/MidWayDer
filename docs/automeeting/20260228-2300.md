## UX/UI 분석

### 발견된 문제점

1. **베스트픽 배너가 정적 div** — 클릭해도 아무 동작 없음. scoreDetailOpenId와 연결 안 됨
2. **영업시간 정보가 뱃지 텍스트만** — "영업 중 / 마감 N분" 으로만 표현, 타임라인이 없어 직관성 낮음
3. **결과 전체 공유 수단 없음** — 개별 카드 공유만 가능, 전체 목록 텍스트 내보내기 불가
4. **카드 뱃지 과부하** — 전체 모드에 뱃지 8개 이상 표시 시 wrap돼 높이 예측 불가 (구조적 한계)
5. **필터 칩 레이아웃** — 5개 칩이 좁은 화면에서 wrap → 실제 카드까지 스크롤 부담

## 구현 (상위 3개)

### 1. 베스트픽 배너 → 점수 분해 자동 열기 (25점) ✅

**변경:** `ResultList.tsx` L1664~1677

- `<div>` → `<button>` 변환
- `onClick`: `setScoreDetailOpenId` 토글 (이미 열려있으면 닫기)
- 우측에 `"📊 분석 / ▲ 접기"` 힌트 텍스트 표시
- border 강조: 분석 열렸을 때 `1.5px solid var(--yellow-400)`

**UX 효과:** 베스트픽 카드 선택 시 자연스럽게 점수 분석 유도, 신규 사용자 교육

### 2. 영업시간 타임라인 시각화 (22점) ✅

**변경:**
- `business-hours.ts`: `getBusinessHoursRange()` 함수 추가
  - 반환: `{ startMin, endMin, is24h } | null`
  - 자정 넘기 처리 (endMin + 24*60)
- `ResultList.tsx`: 이탈 비교 바 아래 타임라인 추가

**UI:**
```
09:00 ─[████████████|███████████]──── 22:00
        영업시작   현재(빨간)   마감
```
- 영업 중: 초록 구간, 마감: 회색 구간
- 현재 시각: 빨간 2px 포인터
- 개시·마감 시각 양끝 텍스트

**UX 효과:** "몇 시에 닫는지"를 텍스트 없이 직관적으로 파악

### 3. 전체 결과 텍스트 내보내기 (20점) ✅

**변경:** `ResultList.tsx` — 결과 요약 헤더 오른쪽 버튼 영역

**UI:** `📋` 버튼 → 클릭 시 `✓ 복사됨` (2초)

**복사 포맷:**
```
[MidWayDer] 스타벅스 검색 결과 (8개)
1. 스타벅스 강남대로점 — +2분 +0.3km [영업 중]
2. 스타벅스 역삼역점 — +4분 +0.6km [영업 중]
...
```
