## A. UX/UI 개선점 (사용자 여정 분석)

### 현재 플로우의 문제점
1. **검색 시작이 번거로움** — 출발/도착 모두 입력해야 검색 가능 (모바일에서 3단계)
2. **재검색 불편** — 카테고리만 바꾸고 싶은데 전체 다시 입력
3. **테마 수동 전환** — 밤에 눈부심, 낮에 어두움 (자동화 필요)
4. **타이핑만 가능** — 운전 중 사용 불가 (음성 입력 없음)
5. **경유지 정보 부족** — 영업시간, 실시간 혼잡도, 별점 등 부재

### 개선 제안
- ✅ **다크모드 자동 전환** — 시간대 기반 (오전 6시~저녁 6시 라이트, 나머지 다크)
- ✅ **음성 검색** — 마이크 버튼으로 핸즈프리 입력 (Web Speech API)
- ⏳ **스마트 출발지** — GPS + 최근 위치 학습으로 "집/회사" 자동 제안
- ⏳ **경로 컨텍스트 저장** — 출발/도착은 유지하고 카테고리만 변경 가능

## B. 신규 기능 제안

### 1. 음성 검색 (Voice Search)
- **설명:** 마이크 버튼 클릭 → "강남역에서 판교역으로 스타벅스" 한 번에 입력
- **가치:** 운전 중 안전성 + 입력 속도 3배 향상
- **차별화:** 카카오맵/네이버지도도 부분 지원이지만, 경유지까지 한 문장은 MidWayDer만의 차별점

### 2. 자동 다크모드
- **설명:** 오전 6시~저녁 6시는 라이트, 나머지는 다크 (수동 전환도 가능)
- **가치:** 눈부심 방지, 배터리 절약
- **차별화:** 대부분 앱이 수동 전환만 지원

### 3. 경유지 영업시간 필터
- **설명:** "지금 영업 중인 곳만" 토글 (Kakao API에서 영업시간 정보 가져오기)
- **가치:** 헛걸음 방지, 실용성 ↑
- **차별화:** 기존 앱들은 영업시간 정보가 있어도 필터로 제공 안 함

### 4. 경로 히스토리 자동 복원
- **설명:** 앱 재접속 시 마지막 검색 경로 자동 로드
- **가치:** 사용자가 이어서 다른 카테고리 검색 가능
- **차별화:** 세션 연속성 강화

### 5. 실시간 교통정보 레이어
- **설명:** 지도에 교통 혼잡도 표시 (Naver Traffic API)
- **가치:** 이탈 시간 예측 정확도 향상
- **차별화:** 경유지 추천 + 교통정보 조합

```typescript
// 자동 테마 전환 함수
const checkAutoTheme = () => {
  const hour = new Date().getHours();
  const shouldBeDark = hour < 6 || hour >= 18; // 오전 6시~저녁 6시는 라이트
  if (autoTheme) {
    const currentTheme = document.documentElement.classList.contains('theme-dark') ? 'dark' : 'light';
    if ((shouldBeDark && currentTheme === 'light') || (!shouldBeDark && currentTheme === 'dark')) {
      setTheme(shouldBeDark ? 'dark' : 'light');
      document.documentElement.classList.toggle('theme-dark', shouldBeDark);
    }
  }
};

// 1분마다 체크
useEffect(() => {
  if (!autoTheme) return;
  const interval = setInterval(checkAutoTheme, 60000);
  return () => clearInterval(interval);
}, [autoTheme]);

// 토글 버튼에 자동 모드 옵션 추가
<button onClick={toggleAutoTheme}>
  {autoTheme ? '🔄 자동' : '🎨 수동'}
</button>
```

### 2. 음성 검색

#### 구현 위치

#### 구현 내용

**1) Web Speech API 래퍼 (`src/lib/voice-search.ts`)**
```typescript
export interface VoiceSearchResult {
  start?: string;
  end?: string;
  category?: string;
  raw: string;
}

export const startVoiceSearch = (): Promise<VoiceSearchResult> => {
  return new Promise((resolve, reject) => {
    if (!('webkitSpeechRecognition' in window)) {
      reject(new Error('이 브라우저는 음성 인식을 지원하지 않아요'));
      return;
    }

    const recognition = new (window as any).webkitSpeechRecognition();
    recognition.lang = 'ko-KR';
    recognition.continuous = false;
    recognition.interimResults = false;

    recognition.onresult = (event: any) => {
      const transcript = event.results[0][0].transcript;
      const parsed = parseVoiceInput(transcript);
      resolve(parsed);
    };

    recognition.onerror = (event: any) => {
      reject(new Error('음성 인식 실패: ' + event.error));
    };

    recognition.start();
  });
};

// "강남역에서 판교역으로 스타벅스" → { start: "강남역", end: "판교역", category: "스타벅스" }
const parseVoiceInput = (text: string): VoiceSearchResult => {
  const patterns = [
    /(.+)에서\s+(.+)[으로|까지]\s+(.+)/,  // "A에서 B로 C"
    /(.+)에서\s+(.+)/,                     // "A에서 B"
  ];

  for (const pattern of patterns) {
    const match = text.match(pattern);
    if (match) {
      return {
        start: match[1]?.trim(),
        end: match[2]?.trim(),
        category: match[3]?.trim(),
        raw: text,
      };
    }
  }

  return { raw: text };
};
```

**2) UI 컴포넌트 추가 (`SearchOverlay.tsx`)**
```typescript
import { Mic, MicOff } from 'lucide-react';
import { startVoiceSearch } from '@/lib/voice-search';

const [isListening, setIsListening] = useState(false);

const handleVoiceSearch = async () => {
  setIsListening(true);
  try {
    const result = await startVoiceSearch();
    if (result.start) onStartChange(result.start);
    if (result.end) onEndChange(result.end);
    if (result.category) onCategoryChange(result.category);
    showToast('음성 인식 완료! 🎤', 'success');
  } catch (err) {
    showToast(err.message, 'error');
  } finally {
    setIsListening(false);
  }
};

// 마이크 버튼 (검색 입력창 옆)
<button
  onClick={handleVoiceSearch}
  disabled={isListening}
  className="p-3 rounded-full active:scale-95 transition-all"
  style={{ background: isListening ? 'var(--accent)' : 'var(--bg-surface)' }}
>
  {isListening ? <MicOff className="w-5 h-5 text-white animate-pulse" /> : <Mic className="w-5 h-5" />}
</button>
```
