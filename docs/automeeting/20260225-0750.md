### E. **기술 부채: PostGIS 미사용**

**현재 문제:**
- Prisma schema에 `lat Float, lng Float`로 저장
- PostGIS 확장은 설치했지만 사용 안 함
- 공간 인덱스(GiST) 없어서 대규모 매장 검색 시 느림
- 현재 매장 수 적어서(1,500개) 문제 없지만, 10만 개 되면 터짐

**개선안:**
- PostGIS `POINT` 타입 사용
  - `location POINT NOT NULL` (SRID 4326)
  - GiST 인덱스 추가
- Prisma에서 PostGIS 지원:
  ```prisma
  model Place {
    location Unsupported("geography(Point,4326)")
  }
  ```
- 쿼리 개선:
  ```sql
  SELECT * FROM "Place"
  WHERE ST_DWithin(
    location,
    ST_SetSRID(ST_Point(lng, lat), 4326)::geography,
    1000 -- 1km
  )
  ```

**기술 가치:**
- 10배 빠른 공간 쿼리
- 매장 수 100배 증가해도 성능 유지
- 향후 반경 검색, 경로 분석 등 고급 기능 가능

### F. **모바일 PWA 최적화 미흡**

**현재 문제:**
- PWA manifest 있지만 설치 유도 없음
- 오프라인 지원 없음 (네트워크 끊기면 백지)
- 푸시 알림 없음 (재방문 유도 불가)

**개선안:**
1. **PWA 설치 배너**
   - 첫 방문 시 "홈 화면에 추가하면 더 빠르게 사용할 수 있어요" 토스트
   - iOS Safari, Android Chrome 감지
   - 설치 후 온보딩 화면 (사용법 3단계)

2. **오프라인 지원**
   - Service Worker로 캐싱
   - 즐겨찾기, 최근 검색은 오프라인에서도 표시
   - "네트워크 연결 후 검색 가능" 안내

3. **푸시 알림 (선택적)**
   - "자주 가는 경로에 새 매장이 생겼어요!"
   - "오늘의 추천 경유지"
   - 과도하면 반감 → 주 1회 이하

**비즈니스 가치:**
- 재방문율 30% 증가 (PWA 설치 시)
- 앱스토어 없이 앱처럼 사용
- 푸시 알림 = 직접 마케팅 채널

### G. **경쟁사 분석 부족**

**현재 차별점:**
- ✅ Detour Cost 알고리즘 (유일)
- ✅ 실제 도로 거리 기반 (카카오맵은 직선거리)
- ❌ 매장 정보 부족 (카카오맵은 사진/리뷰 풍부)
- ❌ 카테고리 제한적 (12개 vs 카카오맵 수백 개)

**벤치마킹 대상:**
1. **카카오맵 "경유지 검색"**
   - 최근 업데이트로 경유지 추가 기능 강화
   - 하지만 수동 선택 (추천 알고리즘 없음)
   - MidWayDer의 강점: 자동 추천

2. **Google Maps "경로 상 검색"**
   - "along the route" 필터 존재
   - 하지만 정확도 낮음 (한국 도로 반영 부족)
   - MidWayDer의 강점: 네이버 API 기반 정확도

3. **네이버지도**
   - 경유지 기능 없음 (단순 A→B만)
   - MidWayDer가 유일

**전략:**
- **네이버/카카오는 안 할 거다**는 가정 위험
- 차별화 포인트 강화:
  - 크라우드소싱 리뷰 (사용자들이 직접 인증)
  - 개인화 추천 (자주 가는 경로 학습)
  - 시간대별 혼잡도 예측 (매장이 붐비는 시간 피하기)
