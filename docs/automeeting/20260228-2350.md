## 구현 완료

### ① ⚡ 필터 프리셋 버튼 2개 (20점)

**위치:** ResultList.tsx — 빠른 필터 칩 섹션 위에 추가

**구현 내용:**
- `activePreset: 'quick' | 'now' | null` 상태 추가
- `applyPreset(preset)` 함수: 같은 프리셋 재클릭 시 전체 필터 해제
- "⚡ 빠른 경유" → `openNowOnly:true + maxDetourMin:5`
- "🔥 지금 당장!" → `openNowOnly:true + maxDetourMin:5 + maxDetourKm:1 + proxScoreOnly:true`
- 개별 필터 칩 클릭 시 `setActivePreset(null)` 자동 해제
- 결과 변경 시 프리셋 자동 초기화

**UX 효과:**
- 가장 자주 쓰는 필터 조합을 원탭으로 적용
- 9개 칩을 일일이 클릭할 필요 없음
- 액티브 시 강조 색상 (accent / red)으로 상태 명확히 표시

### ② 📱 카드 우측 버튼 축소 (16점)

**위치:** ResultList.tsx — 전체 카드 모드 우측 버튼 컬럼

**구현 내용:**
- `overflowMenuId: string | null` 상태 추가
- 기존 7개 버튼 → **Star + Copy + MoreHorizontal(⋯)** 3개로 축소
- "⋯" 탭 시 나머지 5개 버튼 (Phone, Share, Visit, Pin, Memo) 인라인 아코디언 펼침
- 카드 `overflow-hidden` 이슈 회피: 드롭다운이 아닌 **카드 내 인라인 펼침** 방식
- 다른 카드 클릭(handleSelect) 시 오버플로우 메뉴 자동 닫힘
- 결과 변경 시 메뉴 자동 초기화

**UX 효과:**
- 모바일에서 카드 우측 여백이 생겨 콘텐츠 가독성 향상
- 자주 쓰는 기능(즐겨찾기, 복사)은 항상 노출
- 덜 중요한 기능은 숨겨서 cognitive load 감소
