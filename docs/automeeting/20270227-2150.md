## 구현 대상 (이번 세션)

### ① 출발 예정 시각 설정 (36점) ← **핵심**

**변경 파일**: `src/components/search/ResultList.tsx`

**변경 내용**:
- `departureTime` state 추가 (`string`, HH:MM, 기본값: 현재 시각)
- `departureMs` useMemo — 과거 시각이면 다음날로 자동 보정
- `getETAText(result, baseMs?)` — 파라미터 추가 (기본값: `Date.now()`)
- 결과 요약 헤더에 **출발 시각 인풋 UI** 추가:
  - `<input type="time">` 위젯 (흰 배경, 둥근 모서리)
  - "지금" 버튼으로 현재 시각으로 리셋
  - 헤더 하단 구분선 아래에 위치
- ETA 라벨: "지금 출발" ↔ "HH:MM 출발" 동적 표시

**UX 효과**:
- "19:30에 출발 예정" → 경유지 19:45 도착, 목적지 20:10 도착 예상 표시
- 120초 오차 이내면 "지금 출발"로 표시 (과도한 텍스트 변경 방지)

### ② 모바일 즐겨찾기 항상 접근 (28점)

**변경 파일**: `src/app/page.tsx`

**변경 내용**:
- BottomSheet `visible` 조건: `hasResults` → `hasResults || favorites.length > 0 || recentSearches.length > 0`
- BottomSheet `snap` 조건: `hasResults ? bottomSheetSnap : 'collapsed'` (검색 전엔 항상 collapsed peek)
- 검색 전 BottomSheet 내용 추가:
  - **즐겨찾기 경로** 목록 (최대 5개, 각 항목에 ▶ 바로 검색 버튼)
  - **최근 검색** 목록 (즐겨찾기 없을 때, 최대 3개)
- Bottom Quick Bar: 즐겨찾기 & 최근 검색 모두 없을 때만 표시 (중복 방지)

**UX 효과**:
- 앱 진입 → 하단에서 즐겨찾기 경로 peek → 위로 스와이프 → 바로 검색 실행
- 즐겨찾기 없는 신규 사용자는 기존 Bottom Quick Bar 표시 유지
