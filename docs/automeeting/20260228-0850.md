## 구현 내용

### 1. src/lib/place-memos.ts (신규)
- localStorage CRUD: `getPlaceMemos()`, `getPlaceMemo(id)`, `setPlaceMemo(id, text)`, `deletePlaceMemo(id)`
- SSR 안전 (`typeof window === 'undefined'` 가드)
- 빈 문자열 저장 시 자동 삭제

### 2. src/components/search/ResultList.tsx

#### 현재 위치 강조
- `haversineDistanceKm()` 헬퍼 추가 (파일 상단)
- `currentLocation` state — `navigator.geolocation.getCurrentPosition` 1회 호출 (결과 첫 로드 시, 권한 거부 시 무시)
- `closestPlaceId` useMemo — 현재 위치와 각 경유지 간 Haversine 최단 거리로 계산
- **전체 카드**: badges row에 "📍 내 위치 최근접 X.Xkm" (초록 강조) / "📍 X.Xkm" (일반) 뱃지
- **컴팩트 카드**: "📍근접" 초록 뱃지 (가장 가까운 카드만)

#### 경유지 개인 메모
- `memoMap` state (Map<placeId, text>) — 결과 로드 시 localStorage에서 초기화
- `editingMemoId` / `editingMemoText` — 인라인 편집 상태
- 핸들러: `handleEditMemo`, `handleSaveMemo`, `handleCancelMemo` (useCallback)
- **전체 카드 body**: ETA 아래에 편집 중일 때 yellow textarea + 저장/취소 버튼, 메모 있을 때 "#fef9c3 sticky note" 표시
- **전체 카드 액션 컬럼**: ✏️ Pencil 버튼 (메모 있을 때 amber 강조, 없을 때 muted)
- lucide-react에서 `Pencil` 아이콘 추가
