## 구현 내역

### ① 저장된 장소 모아보기 (52점 → 구현 완료)

**파일:** `src/components/search/SearchOverlay.tsx`

**변경 내용:**
```
+ import Star from 'lucide-react'
+ import { getPlaceFavorites, removePlaceFavorite, PlaceFavorite } from '@/lib/place-favorites'

+ state: placeFavorites: PlaceFavorite[]

useEffect (open) {
  + setPlaceFavorites(getPlaceFavorites())
}

+ handlePlaceFavDelete(placeId) — removePlaceFavorite + 상태 갱신

+ {/* Saved places */} 섹션 — 카테고리 칩 아래, 최근 검색 위
  - 가로 스크롤 카드 (min-w-[140px])
  - 카드 클릭 → onCategoryChange(place.category)
  - ✕ 버튼 → handlePlaceFavDelete
  - Spacer 조건도 placeFavorites.length === 0 으로 업데이트
```

**UX 흐름:**
1. 사용자가 SearchOverlay 열기
2. "저장된 장소" 섹션에서 이전에 ⭐한 장소 확인
3. 원하는 장소 카드 탭 → 해당 카테고리 자동 선택 ("스타벅스" 등)
4. 경로 입력 후 검색 → 그 카테고리로 경유지 검색

### ② 컴팩트 모드 발견성 개선 (44점 → 구현 완료)

**파일:** `src/components/search/ResultList.tsx`

**변경 내용:**
```
Before:
<div className="flex items-center gap-2 flex-wrap">
  {/* chips */}
  <button ml-auto className="text-xs ...">≡ 간략</button>
</div>

After:
<div className="flex items-center justify-between gap-2">
  <div className="flex items-center gap-1.5 flex-wrap flex-1 min-w-0">
    {/* chips (좌측 유연) */}
  </div>
  <button shrink-0 className="text-xs font-bold px-3 py-2 rounded-xl ...">
    {/* 항상 우측 고정, 활성 시 그라디언트 강조 */}
  </button>
</div>
```

**개선 포인트:**
- `flex-wrap` 환경에서도 토글 버튼이 항상 우측에 고정 (`shrink-0`)
- 활성 상태: 파란 그라디언트 + 그림자로 명확한 피드백
- 버튼 크기 증가: `px-3 py-2 rounded-xl` (기존 `px-3 py-1.5 rounded-full`)
- 아이콘 크기 강화: `text-sm leading-none`
