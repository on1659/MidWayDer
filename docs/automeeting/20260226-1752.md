## 1단계: UX/UI 개선점 분석 (사용자 여정 중심)

### A. 사용자 여정 — 신규 사용자 (첫 검색)

```
1. 앱 접속 → 검색창 입력
2. 검색 버튼 클릭 → "검색 중..." 바운스 점 3개 표시
3. 3초 기다림 → 사용자: "뭐 하고 있는 거지?" 불안감 ↑
4. 결과 표시
```

**문제:** 검색 중 상태가 단순 스피너 수준. MidWayDer의 핵심 가치인 "경로 분석 → Detour Cost 계산"이 블랙박스처럼 느껴짐.

**기회:** 단계별 진행 메시지("경로 계산 중 → 후보 필터링 중 → 이탈 비용 계산 중")를 보여주면:
- 기다림이 짧게 느껴짐 (체감 속도 개선)
- 앱의 기술적 차별점이 자연스럽게 노출됨 ("이탈 비용 계산 중"이라는 문구 자체가 교육)

---

### B. 사용자 여정 — 루틴 사용자 (집/회사 미설정)

```
1. 평일 오전 8시 앱 접속
2. RoutineBanner? → 아무것도 안 보임 (집/회사 미설정 → null 반환)
3. 사용자는 자동 제안 기능이 있는지조차 모름
4. 주소 직접 입력 반복
```

**문제:** 루틴 자동화의 핵심 전제인 집/회사 설정이 숨겨진 기능(UX 사각지대).
설정 진입점이 없어 DAU 대비 루틴 활성화율이 매우 낮을 것으로 추정.

**기회:** 출퇴근 시간에 집/회사 미설정 사용자에게 인라인 설정 유도 UI를 노출.
설정 → 즉시 루틴 배너로 전환되는 "설정 후 보상" 플로우.

## 4단계: 구현 완료 내역

### ✅ 구현 1: SearchStatus — 단계별 진행 표시

**파일:** `src/components/search/SearchStatus.tsx`

**변경 사항:**
- 정적 "검색 중..." → 단계별 사이클링 메시지
- 아이콘 단계별 변화 (Route → Filter → Calculator → SortDesc)
- 슬라이딩 도트 인디케이터 (완료 단계 파란색, 현재 단계 넓어짐)
- 경과 시간 실시간 표시 (0.2초 간격 업데이트)

**단계 타이밍:**
```
0ms   → "경로 계산 중..."      (Route 아이콘)
1000ms → "경유지 후보 필터링 중..."  (Filter 아이콘)
2500ms → "이탈 비용 계산 중..."    (Calculator 아이콘)
4000ms → "결과 정렬 중..."       (SortDesc 아이콘)
```

**Before:**
```tsx
<span className="text-sm font-medium">검색 중...</span>
// 3개의 바운스 점만 표시
```

**After:**
```tsx
// 단계 메시지 + 아이콘 + 도트 인디케이터 + 경과 시간 (0.0s)
<p>이탈 비용 계산 중...</p>
<div>● ●● ●●● ○  2.3s</div>
```

**UX 효과:**
- 3초 대기가 주관적으로 짧아짐 (진행감 제공)
- "이탈 비용 계산 중"이라는 문구 자체가 앱 차별점 교육
- 기술력에 대한 신뢰감 형성

### ✅ 구현 2: RoutineBanner — 집/회사 인라인 설정 유도

**파일:** `src/components/search/RoutineBanner.tsx`

**변경 사항:**
- 집/회사 모두 저장된 경우 → 기존 루틴 제안 배너 (변경 없음)
- 집/회사 미설정 시 → `SetupMiniForm` 인라인 표시 (신규)
  - 진행 상태 표시 (집 ✓ → 회사 등록)
  - 주소 검색 인풋 + `/api/autocomplete` 활용
  - 자동완성 드롭다운 (최대 4개)
  - 저장 완료 시 즉시 루틴 배너로 전환

**플로우:**
```
출퇴근 시간 감지 (평일 7-9시 / 17-19시)
  ↓
집/회사 저장 여부 확인
  ├── 저장됨 → 기존 루틴 배너 ("출근 시간이에요! 집 → 회사")
  └── 미저장 → SetupMiniForm 표시
        ↓
      주소 검색 → 자동완성 선택 → addSavedLocation() 저장
        ↓
      집/회사 모두 완료 → 루틴 배너로 즉시 전환
```

**Before:**
```tsx
const home = getSavedLocationByLabel('home');
const work = getSavedLocationByLabel('work');
if (!home || !work) return; // ← 조용히 숨어버림
```

**After:**
```tsx
if (!home || !work) {
  setMode('setup'); // ← 설정 유도 UI 표시
}
```

**UX 효과:**
- 루틴 자동화 기능의 실제 사용률 대폭 향상
- "설정 후 즉시 보상" 플로우로 설정 완료율 ↑
- 신규 사용자가 출퇴근 시간에 처음 방문해도 루틴 기능 경험 가능
