## UX/UI 분석

### 문제 인식
결과 카드 기능은 매우 풍부하나, 두 가지 정보 gap이 존재:

1. **방문 뱃지의 시간적 맥락 부재**
   - "방문함" 뱃지만 표시, 언제 방문했는지 불명확
   - visitedAt 타임스탬프가 visit-tracking.ts에 이미 저장되어 있음
   - 사용자 입장: "이게 오늘 방문인지 지난주인지 모르겠다"

2. **1등 결과의 차별화 부족**
   - 1등 카드는 rank badge accent color 차이만 있음
   - 왜 1등인지 이유가 명확하지 않음 (점수 분해 패널을 열어야만 알 수 있음)
   - 사용자 입장: "왜 이게 제일 좋다는 거지?"

## 우선순위 및 구현 선택

**선택: ① + ②** (합산 점수 최상위, 구현 쉬움)

- ① 방문 날짜 표시: visitedIds Set → visitedDates Map (placeId → visitedAt ms) 전환
- ② 베스트 픽 배너: 전체 카드 모드 1등에만 황금 배너 추가, 이유 한 줄 자동 생성
