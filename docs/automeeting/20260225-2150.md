## 1️⃣ 접근성 & 사용성 개선점

### 1-1. 키보드 내비게이션 ⭐⭐⭐
**문제점**: 마우스/터치 없이 키보드만으로 사용 어려움
**제안**:
- `Esc` 키로 오버레이/다이얼로그 닫기
- `Enter` 키로 검색 실행 (현재는 버튼 클릭만 가능)
- `Tab` + `Shift+Tab`으로 포커스 순환
- `/` 키로 검색창 포커스 (Gmail 스타일)
- 화살표 키로 결과 리스트 탐색

### 1-2. 스크린 리더 지원
**문제점**: `aria-label`, `role` 속성 부족
**제안**:
- 주요 버튼에 `aria-label` 추가
- 결과 리스트를 `<ol role="list">` 로 감싸기
- 로딩 중에 `aria-live="polite"` 사용

### 1-3. 에러 메시지 개선 ⭐⭐
**문제점**: 네트워크 오류 시 단순 "오류 발생" 메시지
**제안**:
- 에러 종류별 메시지 (네트워크, API 한도, 데이터 없음)
- "다시 시도" 버튼 추가
- 대안 제시 (예: "인근 다른 카테고리 검색해보세요")

### 1-4. 최근 검색/즐겨찾기 관리 개선 ⭐
**문제점**: 개별 삭제만 있고, 전체 삭제 불편
**제안**:
- "전체 삭제" 버튼 추가
- 삭제 확인 다이얼로그 (실수 방지)
- "삭제 취소" 토스트 (3초간 복구 가능)

### 1-5. 검색 결과 없을 때 대안 제시 ⭐⭐
**문제점**: 결과가 0개면 빈 화면만 표시
**제안**:
- "이 경로에는 {카테고리}가 없어요" 메시지
- "인근 카테고리 추천" (같은 경로에서 다른 카테고리)
- "경로 변경" 제안 (출발지/도착지 수정)
