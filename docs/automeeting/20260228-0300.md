## UX 분석

### 강점
- 3단계 로딩 인디케이터 (스켈레톤 포함) 완성도 높음
- 컴팩트/전체 모드 토글 발견성 개선 완료
- 방문 토글, 스와이프 액션, nameFilter 등 상호작용 풍부

### 발견된 UX 갭
1. **카테고리 전환 마찰** (高): 검색 후 카테고리 변경을 위해 사이드바 스크롤(PC) 또는 오버레이 재오픈(모바일) 필요 → 재검색 흐름 끊김
2. **nameFilter 강조 없음** (低): 텍스트 검색이 필터링만 하고 매칭 텍스트 강조가 없어 검색어 위치 파악 불편
3. **결과 더보기 없음** (中): top 10만 표시, 11위 이후 결과 접근 불가
4. **공유 URL → 자동 검색 미작동** (中): URL 파라미터 파싱 후 자동 실행 안 됨

## 구현 내용

### 1. 빠른 카테고리 전환 칩 (11점)

**위치**: ResultList.tsx — 결과 요약 헤더와 빠른 필터 칩 사이
**구현**:
- `POPULAR_CATEGORIES` 상수 (17개 주요 카테고리)
- 현재 카테고리: accent 색상 강조 (disabled, 탭 이동 없음)
- 다른 카테고리: 수평 스크롤 칩 → 클릭 시 `onCategoryChange` 호출
- `getCategoryIcon()` 이모지 함께 표시
- `scrollbarWidth: none` 으로 스크롤바 숨김 처리

**효과**:
- 탐색 시나리오 (스타벅스 → 이디야로 변경) 클릭 수 3→1로 감소
- "이 근처에도 있어요" 섹션과 차별화 (상단 = 직접 전환, 하단 = 연관 탐색)

```tsx
const POPULAR_CATEGORIES = [
  '편의점', 'CU', 'GS25', '세븐일레븐', '스타벅스', '이디야', '메가커피', '카페',
  '다이소', '올리브영', '약국', '맥도날드', '버거킹', '롯데리아', '주유소', '은행', '우체국',
];
```

### 2. nameFilter 텍스트 하이라이팅 (4점)

**위치**: ResultList.tsx — `highlightText()` 헬퍼 함수 추가
**구현**:
- `highlightText(text, query)` → `React.ReactNode` 반환
- 매칭 부분: `<mark style="background:#fef08a; border-radius:2px">` 으로 강조
- 적용 위치: 전체 카드 모드 이름/주소, 컴팩트 모드 이름
- 대소문자 무시 매칭 (`toLowerCase()`)

**효과**:
- 검색어가 어느 위치에 있는지 즉시 파악 가능
- "강남" 검색 시 "강남구청역" 부분 노란 하이라이팅
