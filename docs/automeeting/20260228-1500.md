## 구현

### ① 활성 필터 요약 바 (22점) — `ResultList.tsx`

**위치**: 필터 칩 영역(이름검색) 아래 → 카드 리스트 위

**조건**: `(openNowOnly || maxDetourMin ≠ null || maxDetourKm ≠ null || proxScoreOnly || unvisitedOnly) && filteredResults.length > 0`

**UI 구성**:
```
[🔽 필터] [영업중 ✕] [+5분 ✕] [1km ✕]     5/15개  [전체 해제]
```

**구현 내용**:
- 각 활성 필터 → 색상 칩 + ✕ 클릭 시 해당 필터만 해제
- `전체 해제` 버튼 → 모든 필터 + `activePreset` 동시 초기화
- `{filteredResults.length}/{results.length}개` 비율 표시

### ② 검색 타임스탬프 + 🔄 갱신 버튼 (18점) — `ResultList.tsx`

**위치**: 헤더 우측 shrink-0 영역 (📋 버튼 왼쪽)

**구현 내용**:
- `searchedAt` state: `results` 변경 시 `Date.now()` 자동 기록
- `getRelativeSearchTime(ms)`: "방금 검색" / "N분 전" / "N시간 전"
- 🔄 버튼 → `onRetry?.()` 호출
