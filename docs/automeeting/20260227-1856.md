## 구현 내용

### 1. 📊 "왜 1등?" 알고리즘 점수 분해 토글 (ResultList.tsx)

**문제**: 카드에 이탈 비용과 이탈 시간이 표시되지만, "왜 이 장소가 1등인지" 알 수 없어 신뢰감 부족

**구현**:
- 기존 뱃지 열 끝에 `📊 N점` 칩 버튼 추가 (클릭 토글)
- 선택 시 아코디언으로 점수 분해 섹션 펼침
- 3개 게이지 바로 시각화:
  - **최종 점수** (파란색): `finalScore`
  - **이탈 비용 70%** (초록색): `100 - detourCost.costScore`
  - **경로 근접도 30%** (보라색): `proximityScore`
- 공식 설명: "이탈비용 70% + 근접도 30%"
- state: `scoreDetailOpenId: string | null` (한 번에 하나만 열림)

**UX 가치**:
- 알고리즘 투명성(Algorithmic Transparency) → 사용자 신뢰 구축
- "왜 경로 초반 매장이 높은 점수?"에 대한 직관적 답변
- 경쟁 서비스 차별화 포인트

### 2. ⚡ 최근 검색 즉시 실행 (SearchOverlay.tsx + page.tsx)

**문제**: 최근 검색 클릭 시 주소만 채워주고 별도로 검색 버튼을 눌러야 함 → 2단계 마찰

**구현**:
- `handleInstantSearch(item: RecentSearch)` 함수 추가 (page.tsx)
  - Zustand store 직접 업데이트 (클로저 문제 우회)
  - `search(item.startAddress, item.endAddress, item.category)` 즉시 실행
- SearchOverlay: `onInstantSearch` prop 추가 + `▶` 버튼 (파란 pill)
- Desktop 패널: 최근 검색 항목에도 동일 `▶` 버튼
- 기존 항목 클릭(주소만 채우기) 동작 유지 → 호환성 확보

**UX 가치**:
- 재검색 마찰 2단계 → 1단계로 감소
- 출퇴근 루틴 사용자 (매일 같은 경로) 효율 극대화
