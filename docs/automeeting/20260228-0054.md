## 구현

### Feature 1: 방문 완료 토글

**변경점:**
- `visitedIds: Set<string>` state 추가
- 초기화: `hasVisited(placeId, routeHash)` 로 기존 방문 기록 복원
- `handleVisitToggle`: recordVisit() 호출 + state 업데이트
- 카드 렌더링: 방문한 카드 → opacity-60 + 우상단 "✓ 방문" 뱃지
- 액션 컬럼: CheckCircle 버튼 (방문/미방문 토글)
- 컴팩트 모드: 초록 체크 아이콘

### Feature 2: 결과 내 이름 검색

**변경점:**
- `nameFilter: string` state 추가
- `filteredResults` useMemo에 nameFilter 조건 추가
- 결과 5개 이상일 때 검색 인풋 표시 (필터 칩 영역 하단)
- 실시간 필터링, X 버튼으로 초기화
- 매칭 개수 표시

## 구현 결과

- ✅ `visitedIds: Set<string>` state + `hasVisited`/`recordVisit` 연동 (visit-tracking.ts)
- ✅ 방문한 카드 opacity:0.65 + 우상단 초록 "✓ 방문" 뱃지 (pointer-events:none)
- ✅ 컴팩트/전체 모드 모두 `CheckCircle`/`Circle` 방문 토글 버튼 (액션 컬럼)
- ✅ routeHash 선언 위치를 useEffect 이전으로 이동 (TS 블록스코프 오류 수정)
- ✅ `nameFilter: string` state + filteredResults useMemo에 includes() 필터
- ✅ 결과 5개 이상시 검색창 표시, XIcon 버튼으로 초기화
- ✅ 필터 초기화 버튼 → nameFilter도 함께 초기화
- ✅ TypeScript 컴파일 오류 없음
