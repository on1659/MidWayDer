## 구현: #1 결과 카드 스와이프 액션 (22점)

### 변경 파일: `src/components/search/ResultList.tsx`

**추가 내용:**
- `swipeInfoRef` (ref): startX/Y, deltaX, locked 상태 추적
- `swipeVisual` (state): UI 렌더링용 transform 값
- `handleCardTouchStart/Move/End`: 터치 핸들러 3종
  - 수직 스크롤 감지 시 자동 취소 (deltaY > deltaX 이면 캔슬)
  - 임계값 80px 초과 시 액션 실행
- `onHoverResult?: (id: string | null) => void` prop 추가

**카드 구조 변경:**
```
<div (outer wrapper, overflow:hidden, rounded-2xl)>
  <div (녹색 네비 힌트, 절대위치 좌측)>네비</div>
  <div (파란색 복사 힌트, 절대위치 우측)>복사</div>
  <button (카드, translateX 적용)>
    ...기존 내용...
  </button>
</div>
```

**UX:**
- swipe-right > 80px: 선호 네비앱 즉시 실행 or 네비 선택 시트 열기
- swipe-left > 80px: 주소 클립보드 복사 + 복사됨 표시
- 스와이프 중: 방향에 따라 힌트 오버레이 opacity 증가 (0~1)
- 스크롤 시 취소: 수직 이동이 수평 이동보다 크면 스와이프 무효화

## 구현: #2 지도↔리스트 호버 동기화 (20점)

### 변경 파일 3개

**`KakaoWaypointMarker.tsx`**:
- `hoveredId?: string | null` prop 추가
- `markerInnersRef: Map<string, HTMLDivElement>` 추가 — 마커 inner 엘리먼트 저장
- 마커 생성 시 `markerInnersRef.current.set(id, markerInner)` 등록
- 별도 `useEffect([hoveredId, selectedId])`: 마커 재생성 없이 style만 업데이트
  - hover: scale(1.25), 강한 그림자
  - 기본: scale(1), 기본 그림자

**`MapContainer.tsx`**:
- `hoveredWaypointId?: string | null` prop 추가
- `KakaoWaypointMarker`에 `hoveredId={hoveredWaypointId}` 전달

**`page.tsx`**:
- `hoveredWaypointId` state 추가
- `MapContainer`에 `hoveredWaypointId` 전달
- Desktop/Mobile `ResultList` 모두에 `onHoverResult={setHoveredWaypointId}` 전달

**UX:**
- 데스크탑에서 결과 카드에 마우스 올리면 지도의 해당 마커가 1.25배로 확대
- 마우스 이탈 시 즉시 원래 크기로 복원
- `transition: transform 0.15s ease`는 마커 inner에 이미 있어 자연스럽게 동작
