## 구현 내용

### ① 🗂 sortBy localStorage 기억 (28점)
**파일:** `src/app/page.tsx`

- `useState` 초기값: `'score'` (불변)
- 신규: 마운트 시 `useEffect` → `localStorage.getItem('sort-by')` 복원
- `sortBy` 변경 시 `useEffect` → `localStorage.setItem('sort-by', sortBy)` 저장
- 유효값 검증: `['score', 'distance', 'duration']` 포함 여부 확인

```typescript
// 복원
useEffect(() => {
  const saved = localStorage.getItem('sort-by') as ... | null;
  if (saved && ['score', 'distance', 'duration'].includes(saved)) setSortBy(saved);
}, []);
// 저장
useEffect(() => {
  localStorage.setItem('sort-by', sortBy);
}, [sortBy]);
```

### ② 🔔 카테고리 전환 재검색 토스트 알림 (35점)
**파일:** `src/app/page.tsx`

- `pendingCategoryToastRef` (useRef) 추가
- `handleCategoryChange` 내 재검색 트리거 시 `pendingCategoryToastRef.current = cat` 설정
- `useEffect([results, isLoading])` — `!isLoading && results.length > 0 && pending` 조건에서 토스트 표시 후 ref 초기화

```typescript
// 카테고리 변경 완료 → "✨ 스타벅스 8개 새로 발견!" 토스트
useEffect(() => {
  if (pendingCategoryToastRef.current && !isLoading && results.length > 0) {
    showToast(`✨ ${pendingCategoryToastRef.current} ${results.length}개 새로 발견!`, 'success');
    pendingCategoryToastRef.current = null;
  }
}, [results, isLoading, showToast]);
```

### ③ 📊 헤더 섹션 접기/펼치기 (40점)
**파일:** `src/components/search/ResultList.tsx`

- `isHeaderExpanded` state 추가 (기본 `true`, localStorage `'header-expanded'` 키로 기억)
- 상단 flex row 우측: `{!isHeaderExpanded && <span>최단 {name}</span>}` + `▲/▼ 접기/펼치기` 버튼
- 접혔을 때 숨기는 영역:
  - 최단 정보 블록
  - 📊 구간별 분포 차트
  - 🕐 출발 예정 시각 설정
  - 🚀 베스트 픽으로 바로 출발 버튼
- 펼쳐진 상태 = 기존 동작 유지

**결과:**
- 헤더 접힘: ~40px (뱃지 한 줄 + 접기 버튼만)
- 헤더 펼침: ~180px (기존 상태)
