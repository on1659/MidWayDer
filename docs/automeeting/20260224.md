- **최근 검색**: 검색 기록 저장/로드/삭제 검증
- **에러 케이스**: API 타임아웃, 네트워크 오류, 빈 결과

## 2) 당장 수정해야 할 사항 (우선순위)

### 🔴 높음

#### 1. CI 배지 추가 (5분 소요)
**문제:** README에 기술 스택 배지만 있고, 실제 프로젝트 건강도를 보여주는 CI 상태 배지가 없음  
**해결:**
```markdown
[![CI](https://github.com/on1659/MidWayDer/actions/workflows/ci.yml/badge.svg)](https://github.com/on1659/MidWayDer/actions/workflows/ci.yml)
```
**효과:** PR/이슈 검토자가 한눈에 빌드 상태 확인 가능

#### 2. E2E 테스트 신뢰성 검증 (15분 소요)
**문제:** CI에서 E2E 테스트가 실제로 통과하는지 미검증  
**해결:**
- 로컬에서 `npm run test:e2e:smoke` 실행 → 통과 확인
- CI 로그에서 Playwright 실행 결과 확인
- 실패 시 스크린샷/비디오 아티팩트 다운로드 → 디버깅

**리스크:** CI가 실패하면 자동 배포가 막히므로 조기 검증 필수

### 🟡 중간

#### 3. API 문서 최소화 버전 작성 (30분 소요)
**문제:** `/api/search` 파라미터/응답 구조가 README에 간략히만 언급됨  
**해결:** `docs/API.md` 생성:
```markdown
## POST /api/search
**요청:**
- `start`: { lat, lng }
- `end`: { lat, lng }
- `category`: string
- `routeType`: 'fastest' | 'shortest'

**응답:**
- `results[]`: { place, detourCost, routes }
- `totalCandidates`: number
- `apiCallsUsed`: number
```

#### 4. 테스트 스크립트 문서화 (10분 소요)
**문제:** `package.json`에 테스트 스크립트가 여러 개 있지만 README에 설명 없음  
**해결:** README "개발" 섹션에 추가:
```markdown
### 테스트
- `npm test` - 유닛 테스트 (Vitest)
- `npm run test:e2e` - 전체 E2E 테스트
- `npm run test:e2e:smoke` - 빠른 스모크 테스트
- `npm run test:e2e:report` - Playwright 리포트 확인
```
