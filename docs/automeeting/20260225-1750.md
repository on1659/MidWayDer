### E. 🎪 **버튼 피드백 강화 - "클릭이 즐겁게" 🎨**

**현재 상태:**
- 기본 hover/active 스타일만
- 클릭 피드백 약함

**문제:**
- 클릭했는지 불분명
- 앱 느낌 부족

**개선안:**
```tsx
// Ripple effect (Material Design)
const [ripples, setRipples] = useState<{x: number, y: number, id: number}[]>([]);

const handleRipple = (e: React.MouseEvent<HTMLButtonElement>) => {
  const rect = e.currentTarget.getBoundingClientRect();
  const x = e.clientX - rect.left;
  const y = e.clientY - rect.top;
  const newRipple = { x, y, id: Date.now() };
  setRipples([...ripples, newRipple]);
  setTimeout(() => {
    setRipples(prev => prev.filter(r => r.id !== newRipple.id));
  }, 600);
};

<button
  onClick={(e) => { handleRipple(e); handleSearch(); }}
  className="relative overflow-hidden active:scale-95 transition-transform"
>
  검색
  {ripples.map(r => (
    <span
      key={r.id}
      className="absolute bg-white/30 rounded-full animate-ripple"
      style={{ left: r.x, top: r.y, width: 100, height: 100 }}
    />
  ))}
</button>

// CSS
@keyframes ripple {
  from { transform: scale(0); opacity: 1; }
  to { transform: scale(4); opacity: 0; }
}
.animate-ripple { animation: ripple 0.6s ease-out; }
```

**기대 효과:**
- 반응성 200% 증가
- 앱 같은 느낌

**우선순위:** ⭐⭐⭐ (20분, 감성 개선)

### F. 🍞 **Toast 알림 시스템 - "명확한 피드백" 📢**

**현재 상태:**
- alert() 사용
- 주소 복사 시 피드백 약함

**문제:**
- alert은 2000년대 느낌
- 사용자 경험 단절

**개선안:**
```tsx
// useToast hook
const [toasts, setToasts] = useState<Toast[]>([]);

const showToast = (message: string, type: 'success' | 'error' | 'info') => {
  const id = Date.now();
  setToasts([...toasts, { id, message, type }]);
  setTimeout(() => {
    setToasts(prev => prev.filter(t => t.id !== id));
  }, 3000);
};

// Toast Container
<div className="fixed top-4 right-4 z-50 space-y-2">
  {toasts.map(toast => (
    <div
      key={toast.id}
      className={`px-4 py-3 rounded-xl shadow-lg animate-slide-in ${
        toast.type === 'success' ? 'bg-green-500 text-white' :
        toast.type === 'error' ? 'bg-red-500 text-white' :
        'bg-blue-500 text-white'
      }`}
    >
      {toast.message}
    </div>
  ))}
</div>

// 사용
showToast('주소를 복사했어요! 📋', 'success');
showToast('GPS 권한이 필요해요', 'error');
```

**우선순위:** ⭐⭐⭐⭐ (15분, 필수 UX)
