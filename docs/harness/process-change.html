운영 상태 흐름

Todo
사람이 아직 정리 중인 작업. 초기에는 active 후보지만 안정되면 제외 가능.
Ready for Codex
Codex 실행 가능한 상태. Symphony가 우선 dispatch하는 목표 상태.
Codex Active
이슈별 workspace에서 Codex가 작업 중인 상태.
Human Review
자동화의 기본 종착점. PR, test evidence, residual risk를 사람이 검토.
Done
사람 검토 이후 종료. 초기 v3에서는 Codex가 직접 밀어넣지 않음.
