## 1. 기능 개요

**현재:** 카테고리 기반 검색만 가능 (다이소, 스타벅스, 올리브영...)
**목표:** 자유로운 경유지 검색 및 추가

## 2. 현재 문제점

### 2.1 사용자 시나리오

**이더의 요구사항:**
> "출발지/도착지 선택하고 경유지를 또 검색해서 넣고 싶어. 지금은 이미 카테고리화된 경유지밖에 못 고르잖아."

**예시:**
```
출발지: 서울역
도착지: 강남역
경유지 검색: "홍대입구역", "이태원 맛집", "강남 CGV"
```

### 2.2 기술적 한계

**현재 구조:**
```typescript
// 카테고리만 검색 가능
POST /api/search
{
  "start": {...},
  "end": {...},
  "category": "다이소" // ← 고정된 카테고리만
}
```

**API 제약:**
- Naver Local Search API는 키워드 검색 지원
- 현재는 카테고리 목록만 제공
- 자유 텍스트 검색 미구현

## 3. 새로운 기능 설명

### 3.1 핵심 기능

**검색창 2가지 모드:**

1. **카테고리 검색 (기존)**
   - 입력: "다이소"
   - 결과: 경로 주변 다이소 매장들

2. **자유 검색 (신규)**
   - 입력: "홍대입구역", "이태원 맛집", "강남 CGV"
   - 결과: 검색한 장소들

### 3.2 UI/UX 디자인

**검색창:**
```
┌─────────────────────────────────────┐
│ 🔍 어디를 들를까? 검색...          │
└─────────────────────────────────────┘

[추천] [다이소] [스타벅스] [올리브영] [주유소]
```

**검색 결과:**
```
검색 결과 (3)

✓ 홍대입구역 (+450m, +3분)
  서울특별시 마포구 양화로 160

✓ 이태원 맛집 - 킹콩부대찌개 (+1.2km, +8분)
  서울특별시 용산구 이태원로

✓ 강남 CGV (+800m, +5분)
  서울특별시 강남구 강남대로
```

**선택된 경유지:**
```
선택됨 (3) [최적화]

1. 홍대입구역
2. 이태원 맛집
3. 강남 CGV

[경로 최적화하기]
```

## 4. 기술 스펙

### 4.1 API 변경

**기존:**
```typescript
POST /api/search
{
  "category": "다이소"
}
```

**변경:**
```typescript
POST /api/search
{
  "query": "홍대입구역", // 카테고리 or 자유 텍스트
  "searchType": "category" | "keyword" // 선택사항
}
```

### 4.2 검색 로직

**카테고리 검색 (기존):**
```typescript
if (query in CATEGORY_LIST) {
  // PostGIS + Naver API 기반 경로 주변 검색
  return searchByCategory(query);
}
```

**자유 검색 (신규):**
```typescript
else {
  // Naver Local Search API로 장소 검색
  return searchByKeyword(query);
}
```

### 4.3 Naver Local Search API

**요청:**
```
GET /v1/search/local.json
?query=홍대입구역
&display=10
&sort=random
```

**응답:**
```json
{
  "items": [
    {
      "title": "홍대입구역",
      "address": "서울특별시 마포구 양화로 160",
      "mapx": "126.9234567",
      "mapy": "37.5567890"
    }
  ]
}
```

## 5. UI/UX 디자인 (모바일 vs PC)

### 5.1 모바일 (375px ~ 768px)

**레이아웃:**
```
┌─────────────────────┐
│   [출발지 입력]      │
│   [도착지 입력]      │
│   [어디를 들를까?]   │ ← 검색창
├─────────────────────┤
│ 추천:               │
│ [다이소] [스타벅스] │ ← 가로 스크롤
│ [주유소] [더보기▼]  │
├─────────────────────┤
│ 검색 결과 (스크롤)  │
│ 1. 홍대입구역       │
│ 2. 이태원 맛집      │
│ 3. ...              │
├─────────────────────┤
│ [선택됨 (3)] [최적화]│ ← 고정 하단
└─────────────────────┘
```

**특징:**
- 세로 방향 최적화
- **하단 시트** (Bottom Sheet) 방식
- 검색창 → 결과 → 선택 → 최적화 플로우
- 터치 친화적 (44px 최소 터치 영역)
- 가로 스크롤로 추천 카테고리 표시

**인터랙션:**
- 검색 결과 카드: 탭 → 선택/해제
- 선택된 항목: 하단에 고정 표시
- 최적화 버튼: 하단에 sticky

---

### 5.2 PC (769px+)

**레이아웃:**
```
┌────────────────────────────────────────┐
│  [출발지] → [도착지]                   │
│  [어디를 들를까? 검색...]              │
├────────────────┬───────────────────────┤
│  추천:          │  지도                 │
│  [다이소]       │                       │
│  [스타벅스]     │  (큰 화면 활용)       │
│  [주유소]       │                       │
├────────────────┤                       │
│  검색 결과:     │                       │
│  □ 홍대입구역   │                       │
│  □ 이태원 맛집  │                       │
│  □ 강남 CGV     │                       │
├────────────────┤                       │
│  선택됨 (3)     │                       │
│  1. 홍대입구역  │                       │
│  2. 이태원 맛집 │                       │
│  3. 강남 CGV    │                       │
│  [최적화]       │                       │
└────────────────┴───────────────────────┘
```

**특징:**
- **2단 레이아웃** (좌: 검색/결과, 우: 지도)
- 지도 크게 표시 (가로 공간 활용)
- 사이드바에 검색 + 결과 + 선택 통합
- 키보드 단축키 지원 (Enter, Escape, Tab)

**인터랙션:**
- 검색 결과 카드: 클릭 → 선택/해제
- 지도와 연동 (마커 표시)
- 호버 효과 (카드 강조)
- 드래그 앤 드롭 (선택 순서 변경)

## 7. 리스크 및 대응

### 7.1 API 호출량 증가

**문제:** 자유 검색은 Naver API 호출량 증가
**대응:**
- 검색 결과 캐싱 (30분)
- Rate limiting (분당 5회)

### 7.2 검색 결과 품질

**문제:** 자유 검색은 결과 품질이 낮을 수 있음
**대응:**
- 정확도 기반 정렬
- "검색 결과가 없습니다" 안내

### 7.3 기존 기능 호환성

**문제:** 기존 카테고리 검색 사용자 혼란
**대응:**
- 카테고리 버튼 유지
- 자연스러운 UX 전환
