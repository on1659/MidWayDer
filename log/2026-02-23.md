# 진행 로그 (2026-02-23)

## 개요
MidWayDer 경유지 검색 알고리즘 개선 및 지도 경로 표시 개선 작업 기록.

---

## 변경사항

### 1) 검색 알고리즘 문서화
- `docs/search-algorithm.md` 추가
- `/api/search` 플로우, 공간필터/근접도/Detour Cost 계산 정리
- 커밋: `docs: add search algorithm overview`

### 2) 비정상 shortest 경로 제거 로직
- Kakao shortest 경로가 과도하게 우회(서울역 경유 등)되는 케이스 대응
- shortest가 fastest 대비 지나치게 느리면 제외 (`durationRatio >= 1.35`)
- `primaryOriginalRoute`는 fastest 우선 사용
- 커밋: `fix(search): drop slow shortest route`

### 3) 도착지 근처 후보 제외 제거
- 경로 진행률 95% 이후 후보 제외 로직 삭제
- 도착 후 들르는 경유지까지 포함
- 커밋: `fix(search): keep destinations near arrival`

### 4) 최대 허용 이탈거리 축소
- `maxDetourDistance` 기본값 5000m → 3000m
- 과도하게 먼 후보(의미 없는 경유지) 제거 목적
- 커밋: `tune(search): reduce max detour distance`

### 5) 고속화도로/고속도로 구간 색상 분리 (옵션 B)
- Kakao Directions `roads` 기반 세그먼트 추출
- 세그먼트별 도로명 키워드로 고속화도로 추정
- 지도 경로: 고속화도로(주황), 일반도로(파랑) 분리 표시
- 추가 API 호출 없음
- 커밋: `feat(map): colorize highway segments`

### 6) 디버그 스크립트
- `scripts/debug-route.ts` 추가
- 특정 출발/도착지 기준으로 shortest/fastest 경로 확인 및 서울역 근처 통과 여부 점검
- 커밋: `fix(search): drop slow shortest route` 포함
